# 交互验收清单（I-01～I-19）

> 2026-11-18 · 依据 [交互设计文档 §15](../交互设计文档.md)。
> 「自动」= 每次跑测试都会验证；「手工」= 需要人在模拟器或真机上按步骤确认，勾选后注明设备、系统版本和日期。

## 运行自动验收

```sh
xcodebuild test -scheme TuneHaven -destination 'platform=iOS Simulator,name=iPhone 17' \
  -parallel-testing-enabled NO -only-testing:TuneHavenUITests/AcceptanceUITests
```

- 并行运行时模拟器克隆偶尔启动失败，验收请串行（`-parallel-testing-enabled NO`）。
- 每次启动用 `TUNEHAVEN_FRESH_STORE` 指向 tmp 里的新库（仅 DEBUG），种子为 4 首 2 分钟静音 WAV「交互测试1…4」。
- 失败时测试会附上当时的界面树（附件名 `tree-<行号>`）。

## 手工步骤

勾选格式：`- [x] 步骤 —— 设备 / iOS 版本 / 日期 / 结果`

### I-09 进度与关闭拖动
- [ ] 全屏播放器拖动进度条到中间，松手后：原本播放的继续播放，原本暂停的保持暂停
- [ ] 在进度条上横向拖动时，播放器不会被下拉关闭；在封面区域下拉才关闭

### I-10 歌词
- [ ] 播放中手动滑动歌词，滑动期间不被拉回当前句；停止约 3 秒后自动回到当前句
- [ ] 手动浏览时出现「回到当前句」，点击立即定位
- [ ] 系统字号调大后歌词随之放大、不截断

### I-12 系统切换日夜
- [ ] 云霞、晴屿、月晕各一次：播放中从控制中心切换深色／浅色，迷你播放器、Tab、列表、全屏播放器、弹层同步变色
- [ ] 切换前后播放进度、队列、当前页面不变

### I-14 导入
- [ ] 一次选择：1 个新文件 + 1 个已存在文件 + 1 个不支持格式（如 .txt），结果页分别显示 成功 1 / 重复 1 / 不支持 1，不显示「全部失败」
- [ ] 导入中点「停止」，显示「正在停止」，已导入的保留

### I-16 权益（需 Free：试用期已过且未购买，或用沙盒账号）
- [ ] 导入 → WebDAV：先出权益说明；关闭后回到导入方式页
- [ ] 播放无损歌曲：停在该曲并出软付费墙，不静默跳过
- [ ] 歌词 → 在线搜索：出付费墙；关闭后回到歌词页，本地导入仍可用

### I-17 真机：中断与耳机
- [ ] 播放中来电／闹钟，结束后：原本播放的恢复，原本暂停的不自动播放
- [ ] 播放中拔出有线耳机或断开 AirPods：暂停，界面显示暂停
- [ ] 音频输出按钮显示的设备名与实际一致（AirPods 等）

### I-19 真机：辅助功能
- [ ] VoiceOver 走一遍：音乐库 → 播放歌曲 → 全屏播放器 → 歌词 → 队列 → 关闭；每个控件都读出名称和状态（播放／暂停、已喜欢、当前模式）
- [ ] 开启「减少透明度」：悬浮 Tab、迷你播放器、弹层有不透明背景，文字可读
- [ ] 开启「减少动态效果」：歌词切行、唱片旋转、页面转场不做大幅动画
- [ ] 最大辅助字号：设置页、导入页、付费墙的按钮都能滚动到并点击
