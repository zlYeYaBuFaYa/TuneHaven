# TuneHaven 项目文档

> 本文是工程手册：技术栈、目录、数据库、配置、构建与测试。功能与规则见《需求文档》，架构与实现见《技术设计文档》。

## 1. 项目概述

TuneHaven 是 iOS 本地优先音乐播放器：曲库、有损播放、歌单和本地导入离线免费可用，Premium 解锁无损播放、高级主题、WebDAV 导入和在线歌词。

| 项目 | 值 |
|------|-----|
| Bundle ID | `demo.TuneHaven` |
| 版本 | 1.0（MARKETING_VERSION） |
| 设备 | iPhone、iPad（TARGETED_DEVICE_FAMILY = 1,2） |
| 主分支 | 开发主线为 `release`；`main` 目前停在较早版本 |

## 2. 技术栈

| 类别 | 选型 |
|------|------|
| 语言 | Swift 5.0（SWIFT_VERSION） |
| UI | SwiftUI |
| 架构 | Clean Architecture + MVVM，五层（见技术设计 §1） |
| 持久化 | Core Data（双上下文）+ UserDefaults + Keychain |
| 音频 | AVFoundation（AVPlayer）、MediaPlayer |
| 网络 | Network Framework（自写 HTTP 服务器）、URLSession |
| 内购 | StoreKit 2 |
| 并发 | `@MainActor` + async/await + Combine |
| 测试 | XCTest |
| 依赖 | 无第三方依赖，无 Swift Package，单 App Target |
| 最低系统 | iOS 18.0（所有 Target 的 IPHONEOS_DEPLOYMENT_TARGET） |
| 开发工具 | Xcode 27+（iOS 27 SDK；iOS 26+ 使用 Liquid Glass，见技术设计 §8.3） |

## 4. 数据库（Core Data）

模型文件 `Core/Persistence/MusicPlayer.xcdatamodeld`，由 `CoreDataStack` 加载，`MigrationManager` 负责迁移。

### SongEntity（歌曲）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| title / artist / album | String | 默认 "" / 未知艺术家 / 未知专辑 |
| duration | Double | 秒 |
| fileHash | String | SHA256，用于去重 |
| fileRelativePath | String | 相对 `Documents/Music/`；`missing/` 前缀表示音频缺失 |
| fileSize | Int64 | 字节 |
| format | String | 扩展名 |
| sampleRate / bitRate / channels / encoder | — | 音频参数 |
| trackNumber / year / genre | — | 标签信息 |
| coverImagePath / lyricsPath | String? | 封面、歌词路径 |
| lyricsSource | Int16 | 0 内嵌 / 1 文件 / 2 手动 |
| importDate | Date | 导入时间 |
| playCount / lastPlayedDate | — | 播放统计 |
| isFavorite / favoriteDate | — | 收藏 |
| softDeleted / deletedAt | — | 软删除 |

索引：byArtist、byAlbum、byImportDate、byFileHash、bySoftDeleted。

### PlaylistEntity（歌单）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| name / desc_ | String | 名称、简介 |
| isSystem / systemType | Bool / Int16 | systemType：0 普通、1 我喜欢、2 最近播放 |
| groupId | UUID? | 所属分组 |
| sortOrder | Int32 | 排序 |
| autoCoverPath / autoCoverHash / customCoverPath | String? | 封面 |
| createdAt / updatedAt | Date | 时间 |

关系：`songs` → PlaylistSongEntity（一对多）。

### 其他实体

| 实体 | 字段 | 说明 |
|------|------|------|
| PlaylistSongEntity | playlistId、songId、sortOrder、addedAt；关系 `playlist` | 歌单与歌曲的多对多关联 |
| PlaylistGroupEntity | id、name、sortOrder、createdAt | 歌单分组（歌单通过 groupId 关联） |
| PlayRecordEntity | id、songId、playedAt；索引 bySongId、byPlayedAt | 播放记录，用于「最近播放」 |
| SearchHistoryEntity | id、keyword、tabContext、searchedAt | 搜索历史，tabContext 区分标签 |
| MissingSongReferenceEntity | id、playlistId、title、artist、album、duration、createdAt | 模型中保留，当前代码未使用 |

## 5. 配置

### 5.1 Info.plist

| 键 | 值 | 用途 |
|----|-----|------|
| UIBackgroundModes | audio | 后台播放 |
| NSAppTransportSecurity.NSAllowsLocalNetworking | true | 局域网 HTTP |
| NSLocalNetworkUsageDescription | 需要访问本地网络以在设备间传输音乐和歌单 | WiFi 传输、分享直传 |

| UTExportedTypeDeclarations | `com.tunehaven.backup`，扩展名 `tunehaven` | 备份包类型 |
| UILaunchScreen | 颜色 LaunchBackground | 启动屏 |

## 7. 开发规范

- 颜色一律通过 `ThemeColorPalette` 获取，新组件必须适配 4 套主题
- 文件路径一律通过 `SandboxPathManager` 获取
- UserDefaults 键名一律定义在 `AppStorageKey`
- Presentation 通过 `@EnvironmentObject` 取 Service，不直接用 `.shared`
- Core Data 写操作一律走 `CoreDataStack.performBackground`
- 新的 Premium 功能：在 `PremiumFeature` 加 case，并在 Domain 层入口检查 `canAccess`，不能只靠界面上锁
