## 1. 产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | TuneHaven |
| 产品类型 | iOS 本地优先音乐播放器 |
| 目标平台 | iOS 18.0+（iPhone / iPad） |
| 目标用户 | 18–45 岁、有本地音乐收藏的 iOS 用户 |

曲库、有损播放、歌单和本地导入完全离线可用，无需订阅；无损播放、WebDAV 导入、在线歌词属于 Premium（见 3.11）；三套主题全部免费。不内置广告，曲库默认不离开设备。

典型场景：通勤离线听歌、运动时后台播放、工作时循环播放、睡前定时关闭。

产品约束：

- iOS 沙盒不能扫描整个文件系统，导入必须由用户主动发起
- Apple Music 中受 DRM 保护的歌曲无法导出，导入时过滤掉

## 2. 页面结构

- **底部 Tab**：音乐库 / 歌单 / 设置，悬浮圆角底栏，图标加文字，选中项用实心图标与浅色胶囊底标识。再次点击当前 Tab 不做任何事。各 Tab 的导航栈互相独立，切换 Tab 不丢失页面状态
- **迷你播放器**：悬浮在 Tab 栏上方，所有 Tab 共用。显示封面、歌名、艺术家、播放/暂停、下一首和细进度线；点击主体展开全屏播放页，点击播放/暂停或下一首不展开。收藏在全屏播放页和歌曲菜单中操作
- **全屏播放页**：自上而下为收起／正在播放来源／更多 → 大封面 → 歌名、艺术家与收藏 → 音质标签 → 歌词预览 → 进度条 → 播放模式、上一首、播放／暂停、下一首、播放队列 → 音频输出。可进入歌词全屏页、播放队列，以及「更多」里的定时关闭、倍速、封面样式。向下拖拽封面区域关闭
  - 封面：云霞、月晕默认方形；晴屿默认唱片样式（圆形展示，不改原封面）。「更多」中可在完整方形与唱片之间切换并记住
  - 音质标签只显示真实数据：无损歌曲显示 LOSSLESS，已知采样率显示如「48 kHz」；不显示位深，未知字段隐藏
  - 歌词预览显示读取中、匹配中、无结果、失败或器乐曲状态；点击进入歌词页，可搜索、粘贴或导入 LRC 文件
  - 音频输出显示系统当前输出设备名称（本机扬声器时显示「音频输出」），点击打开系统设备选择

| Tab | 内容 |
|-----|------|
| 音乐库 | 顶部标签「全部 / 艺术家 / 专辑」+ 搜索栏 + 列表 |
| 歌单 | 顶部「搜索你的歌单」；「我喜欢」「最近播放」两张收藏夹卡；「我的歌单」含分组入口、排序入口、最近更新歌单的重点卡和其余歌单 |
| 设置 | 见 3.12 |

## 3. 功能规格

### 3.1 音乐导入

| 方式 | 说明 | 档位 |
|------|------|------|
| 文件导入 | 用系统文件选择器选取音频文件 | Free |
| Apple Music 导入 | 扫描设备上已下载的本地媒体库，过滤 DRM 歌曲后导出一份独立副本（之后在「音乐」App 删除不受影响）。MP3、AAC、ALAC、PCM 原样保留音质；已导入过的歌曲直接跳过；点「关闭」后导入在后台继续 | Free |
| 云盘导入 | 通过系统文件选择器从已安装的云盘 App 选取文件，目前列出百度网盘 | Free |
| WiFi 传输 | 同一局域网内用电脑浏览器上传，支持拖拽和扫码打开页面 | Free |
| 从其他 App 打开 | 在其他 App 中用「用 TuneHaven 打开」分享音频文件，自动导入 | Free |
| WebDAV 导入 | 管理多个 WebDAV 账户（如坚果云、NAS），浏览目录并下载导入。最多同时下载 3 个；不同目录下的同名文件分别导入；下载中可取消，取消后不再下载也不导入 | Premium |

**统一导入界面**：音乐库「+」与设置的五种导入入口共用 `ImportFilesView`。设置快捷入口会在导入页展示后打开所选方式。只有选择 Apple Music 时请求媒体库权限，只有手动开启 WiFi 服务时启动监听。WebDAV 无权限时在导入流程内展示权益说明，关闭后仍回到导入页。

**取消与结果反馈**：取消系统文件选择不报错；文件／云盘导入页面内分类展示结果，部分成功不标成全部失败。导入过程中禁用重复提交，停止请求显示“正在停止”，已导入的歌曲保留；关闭页面本身不停止文件／云盘／Apple Music 导入。WebDAV 下载阶段可停止，进入保存入库阶段后等待结果，不提供无效停止操作。

**支持格式**：MP3、M4A、AAC、ALAC、WAV、FLAC、AIFF/AIF、CAF。单文件不超过 500MB。

**无损判定**（决定是否需要 Premium）：FLAC、WAV、AIFF、CAF 为无损；M4A/ALAC 编码器为 ALAC，或码率高于 600kbps 时为无损；其余为有损。

**元数据**：导入时读取标题、艺术家、专辑、时长、封面、内嵌歌词、采样率、码率等。原生 FLAC 额外读取 Vorbis Comment 标签、图片块与 STREAMINFO；旧记录不自动批量回填。缺失时，标题用文件名，艺术家显示「未知艺术家」，专辑显示「未知专辑」，封面用占位图。

**去重**：按文件内容（SHA256）判重，重复文件跳过。已删除（仍在 30 秒撤销窗口内）的歌曲不算重复：重新导入同一文件会作为新歌曲入库，不继承原来的收藏、播放次数和歌单。

**进度与结果**：导入中显示进度条、当前文件名、已完成数/总数和预计剩余时间。结束后弹窗汇总，页面内分类统计：成功 / 重复跳过 / 格式不支持 / 超过大小 / 失败。

**WiFi 传输规则**：

| 规则 | 说明 |
|------|------|
| 密码保护 | 可选 6 位数字密码，可自动生成或自定义。开启后，浏览器必须先通过密码验证才能上传；停止服务或更换密码后需要重新验证 |
| 防暴力破解 | 同一 IP 连续输错 5 次，冷却 30 秒 |
| 新设备提醒 | 传输过程中有新设备连接时提醒用户确认 |
| 安全提示 | 使用 HTTP 明文传输，页面上提示风险 |
| 逐个导入 | 收到的文件按到达顺序逐个导入；备份或其他导入进行中时排队等待。App 内列表显示每个文件的真实结果：等待导入 / 正在导入 / 已导入 / 曲库中已存在 / 导入失败（附原因）。关闭传输页后，已收到的文件继续导入完 |

### 3.2 播放

**基础控制**：播放/暂停、上一首/下一首、拖动进度。上一首在已播放超过 3 秒时回到本曲开头。进度条触控区 44 pt，拖动时只预览时间，松手才跳转，并保持原来的播放／暂停状态；时长未知时不能拖动。

**播放模式**：

| 模式 | 下一首 | 队列全部播完后 |
|------|--------|----------------|
| 顺序播放 | 按顺序找下一首未播放的歌 | 停止 |
| 单曲循环 | 重复当前歌曲 | — |
| 列表循环 | 按顺序找下一首未播放的歌 | 清除已播放标记，从头开始 |
| 随机播放 | 在未播放的歌中按权重随机挑选 | 清除已播放标记，继续随机 |

**跳过偏好**：每首歌记录一个「不喜欢次数」（上限 5）。随机播放的权重为 `1 / (1 + 不喜欢次数)`；顺序和列表循环会跳过不喜欢次数 ≥ 3 的歌。

**倍速**：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 1.75x / 2.0x，变速不变调。速度记忆可选「全局」（切歌保持当前速度，默认）或「单曲」（每首歌单独记忆）。

**定时关闭**：15 / 30 / 45 / 60 / 90 分钟，可中途取消。到时自动暂停。

**后台与锁屏**：退到后台继续播放。锁屏和控制中心显示歌名、艺术家、封面和进度，支持播放/暂停、上一首/下一首和拖动进度。来电等中断结束后，只有中断前正在播放才自动恢复；拔出耳机时暂停。打开 App 但未开始播放时不打断其他 App 的音频。

**启动恢复**：冷启动时恢复上次播放的歌曲，但不自动开始播放。

### 3.3 播放队列

- 播放某个列表中的歌曲时，用该列表（全部歌曲、艺术家、专辑、歌单、最近播放等）重建队列
- 查看队列、拖拽排序、移除单首、清空、把当前队列保存为歌单
- 移除当前播放的歌曲或清空队列时，当前歌曲继续播完（队列外播放）；之后从原后继项继续，无后继则停止。队列页顶部显示「队列外播放」标记，并说明播完后继续哪首或停止
- 清空队列前确认，说明只清空队列、当前歌曲会播完后停止
- 从音乐库删除正在播放的歌曲时，立即切到队列中的下一首（原来暂停则保持暂停），没有下一首则停止
- 长按歌曲选择「下一首播放」，插入到当前歌曲之后
- 容量上限 999 首
- 已播放的歌留在队列中，只做标记
- 队列不持久化，关闭应用后清空

### 3.4 音乐库

**浏览**：

| 视图 | 展示 | 说明 |
|------|------|------|
| 全部 | 列表 | 可排序，可按格式筛选（MP3、M4A、FLAC 等） |
| 艺术家 | 分组列表 | 点击进入艺术家详情 |
| 专辑 | 封面网格 | 点击进入专辑详情 |

**详情页**：专辑详情为大封面、专辑名、艺术家（可点进艺术家）、年份／曲目数／总时长，「播放全部」「随机播放」，下方按曲序列出曲目（长按可下一首播放、加入歌单、删除）。艺术家详情为首字头像、专辑与歌曲数，「播放全部」「随机播放」，专辑横向陈列，以及全部歌曲。「随机播放」会把播放模式切为随机。

**搜索结果**按歌曲、艺术家、专辑分组，各显示数量，超出时可「查看全部」。搜索历史按当前分类分别保存，可左滑删除单条，清空前确认。

**排序**：名称、艺术家、专辑、导入时间、文件大小、时长。再次点击当前排序项切换升/降序；点击其他项切换过去并默认升序。排序选择会被记住。

**歌曲操作**（各列表按场景提供其中一部分）：

| 手势 | 操作 |
|------|------|
| 右滑 | 喜欢 / 取消喜欢 |
| 左滑 | 删除（从音乐库删除，或在自建歌单里移出歌单） |
| 长按，或歌曲行右侧「更多」按钮 | 喜欢、下一首播放、添加到歌单、从音乐库删除（歌单内为「移出歌单」） |

「下一首播放」成功后提示「已添加到下一首播放」；队列已满 999 首时提示「播放队列已满，请先移除一些歌曲」，原队列不变。

**音乐库首页**：右上角「+」打开导入方式选择（与设置中的导入入口相同，含 WebDAV）。「全部」下方有「继续听」卡片，只显示本机上次的有效歌曲，点击按正常播放流程播放并展开播放页；没有记录或音频缺失时不显示。歌曲行显示封面、歌名、艺术家（专辑）、正在播放标记（暂停时静止）和「更多」按钮。曲库为空时显示「还没有音乐 / 把喜欢的音乐带进来」和「导入音乐」。「专辑」先显示「最近添加」（按专辑内最新导入歌曲的时间倒序，最多 6 张，横向滑动），再显示全部专辑网格；「艺术家」列表显示首字头像、歌曲数与专辑数。

**收藏**：收藏状态和系统歌单「我喜欢」双向同步。

**删除与撤销**：从音乐库删除需要先确认。删除后底部提示条保留 30 秒，可撤销；超时后才真正删除文件。同一个文件只有在没有任何歌曲记录引用时才会被物理删除。从歌单移出只解除关联，不删歌曲。

**音频缺失**：从仅含元数据的备份恢复的歌曲显示「未找到」。之后导入同一首歌的文件时自动挂回原记录，保留收藏和播放次数。

### 3.5 搜索

档位为 Free，不需要联网，也不会触发付费墙。

**范围与匹配**：搜索歌名、艺术家、专辑。

- 原文包含：「里香」能搜到「七里香」，拉丁字母不区分大小写
- 拼音全拼：从音节开头做前缀匹配，`zhou`、`zh` 能搜到「周杰伦」，`qili` 能搜到「七里香」
- 拼音首字母：连续匹配，`qlx` 能搜到「七里香」
- 容错：拉丁输入长度 ≥ 3 时，允许和整段全拼或整段首字母相差 1 个字符。单个拉丁字母不走拼音匹配
- 拼音在本机生成（多音字取常用读音），不联网，不上传曲库

**音乐库搜索**：输入停止 300ms 后搜索。搜索框内的清除按钮只清空输入并保留焦点；「取消」退出搜索并收起键盘。无结果显示「没有找到相关音乐」并提示试试拼音首字母。在「艺术家」「专辑」标签下只匹配对应字段。结果中的歌曲支持删除、收藏、添加到歌单、下一首播放，操作后结果自动刷新。

**歌单内搜索**：在歌单详情顶部，输入即过滤，匹配规则同上。有搜索词时隐藏歌单头部（封面、名称、简介）。

**无结果**：显示空状态，并提示「试试拼音首字母」。

**搜索历史**：

- 搜索框获得焦点且内容为空时显示
- 「全部 / 艺术家 / 专辑」三个标签分别保存，每个标签最多 10 条，按时间倒序，相同关键词只保留最新一次
- 点击历史词立即搜索；左滑删除单条；可清空当前标签的历史
- 设置 → 存储与隐私 可清除全部搜索历史

### 3.6 歌单

**系统歌单**（不可删除、不可重命名、不能分享）：

- 我喜欢：始终排第一，内容来自歌曲的收藏状态，按收藏时间倒序
- 最近播放：去重展示，时间范围可设为 3 / 7 / 14 / 30 天或全部（默认 7 天），最多加载 1000 首

**自建歌单**：

- 新建/编辑：名称必填，简介选填。新建时自动聚焦名称；错误显示在名称下方；提交中不能重复点击，失败保留输入。编辑有未保存修改时，取消或下拉关闭会询问「放弃修改／继续编辑」；未修改时「保存」不可点
- 添加到歌单：点选歌单后加入并提示「已添加到「歌单名」」；失败时留在弹层内说明原因
- 命名规则：自动去掉首尾空白；不能为空；不能叫「我喜欢」或「最近播放」；不限制特殊字符
- 删除歌单需确认，提示「删除歌单不会删除音乐库中的歌曲」；入口为左滑或歌单行「更多」菜单
- 歌单列表点「排序」进入排序态后拖动调整顺序，也可点行尾菜单上移／下移
- 首页重点卡展示最近更新的自建歌单（歌曲数与总时长）；点卡片主体进入详情，点「播放歌单」以该歌单为队列，从第一首可播放的歌曲开始。没有自建歌单时显示「创建第一个歌单」
- 「搜索你的歌单」只按名称筛选自建歌单，匹配规则同音乐库搜索（原文、拼音、首字母），不搜索歌单内歌曲
- 封面：自动取前 4 首歌的封面拼成 2×2 宫格，不足 4 首时用占位图补齐
- 详情页：顶部搜索框（输入即过滤，有搜索词时隐藏封面与简介）；封面拼图、名称、简介、曲数与总时长，「播放全部」「随机播放」；「歌曲 N」标题旁为排序菜单。空歌单显示「这个歌单还没有歌曲」与「添加歌曲」
- 「我喜欢」「最近播放」详情页：图标头部、曲数（最近播放另显示时间范围）与总时长、「播放全部」「随机播放」；歌曲菜单提供下一首播放与添加到歌单，「我喜欢」可取消收藏（可撤销）

自建歌单详情的“歌单操作 → 调整歌曲顺序”支持拖动和上移／下移，取消放弃，保存后落盘并按“歌单顺序”显示；字段排序仍可切换。调整不改当前播放队列，系统歌单不提供手动排序。

**分组**：新建、重命名、删除分组（确认后组内歌单回到未分组，歌单不删除），把歌单移入或移出分组（右滑或长按），分组可排序。

**批量添加歌曲**：歌曲按艺术家分组展示，支持搜索、全选/取消全选/反选；已在歌单中的歌曲不可选，并标注「已在歌单中」，不计入全选。提交按钮显示选中数量，零首不可提交。

### 3.7 歌词

**来源优先级**：

1. 音频文件内嵌歌词
2. 本地歌词文件：用户导入的 .lrc 文件或手动输入的歌词
3. 在线自动匹配（Premium，可在设置里关闭）：依次尝试精确匹配、歌名+艺术家、仅歌名、简化歌名（去掉括号、feat.、remix 等）。全部失败后，这首歌 7 天内不再自动匹配；网络错误不计入

**手动操作**：在线搜索并选择歌词（Premium）、导入 .lrc 文件、粘贴 LRC 或纯文本歌词、删除歌词。精确匹配到器乐曲或手动选择器乐曲结果后保存“器乐曲（无歌词）”标记；重启及备份恢复后保留，重新添加歌词可替换。删除歌词同样记为“已删除”：之后不再读回内嵌歌词、不自动在线匹配，重启和备份恢复后保留，重新添加歌词即替换。

**显示**：

- 上方为小封面、歌名、艺术家与收藏；歌词左对齐，当前行靠近阅读区中心，长句自然换行
- 自动跟随进度。当前行加粗，并按行内进度从左到右填充（日间用主题强调色，黑夜用浅色）；其他行距离越远越淡，但保持可读
- 手指拖动歌词时暂停跟随，停下 3 秒后恢复；底部「回到当前句」立即恢复。点击某行跳到该行时间，保持原来的播放／暂停状态
- 底部轻工具条：缩小／放大字号（与双指缩放共用 0.8–2.0 倍）、简体／原文、回到当前句（仅时间轴歌词）
- 歌词字形：默认显示简体（繁体自动转换），可在 设置 → 播放 或歌词页工具条改为「原文」。播放页预览和歌词全屏页使用同一设置
- 纯文本歌词可滚动阅读、调整字号与字形，不逐行高亮
- 歌词读取、匹配、无结果、网络失败、保存失败与器乐曲分别展示；失败可重试，始终保留「导入 LRC」与「搜索／粘贴」（在线搜索标明 Premium）。网络错误不进入七天失败缓存
- 点击收起、右滑，或在歌词区以外下滑返回播放页

### 3.8 主题

| 主题 | 日间 | 黑夜 | 档位 |
|------|------|------|------|
| 云霞（默认） | 粉蓝柔光 | 玫瑰雾、烟蓝与低亮度紫 | Free |
| 晴屿 | 薄荷与暖杏 | 墨绿与琥珀 | Free |
| 月晕 | 冰蓝与淡紫 | 午夜蓝与烟紫 | Free |

- 主题只决定色系，日间／黑夜跟随系统外观；系统切换深浅时主题、曲目、队列与页面位置不变
- 色值与视觉规范见 [UI 设计文档](UI设计文档.md) §4；背景为不透明底色叠三束柔光，减少透明度时改为纯色
- 切换后立即生效并保存，下次启动恢复
- 旧主题自动换算：素云白简、暮光玫瑰 → 云霞；晴空蔚蓝 → 晴屿；星际穹顶 → 月晕；更早版本的主题 → 云霞。恢复旧备份中的旧主题同样换算
- 文字颜色对比度在六种外观上满足 4.5:1

### 3.9 二维码分享直传

两台设备在同一 WiFi 下，直接传输歌曲或歌单，不经过外部服务器或 iCloud。档位为 Free。

**入口**：设置 → 分享 →「发送歌曲 / 歌单」或「扫码接收」。

**发送**：选择歌曲或歌单（可多选）→ 生成二维码 → 等待对方扫码 → 显示传输进度。

**接收**：扫码 → 显示传输分析（新增歌曲数、已有可跳过数、各歌单关联本地歌曲数、预估大小）→ 确认后接收 → 显示传输阶段、进度和当前文件 → 完成后汇总（接收数、跳过数、新建歌单数、关联本地歌曲数）。

**规则**：

| 规则 | 说明 |
|------|------|
| 跳过已有歌曲 | 接收端已有的歌曲（标题 + 艺术家相同）不再传输 |
| 歌单关联 | 歌单中接收端已有的歌曲直接关联本地歌曲 |
| 分组 | 携带分组名，接收端没有该分组时自动创建 |
| 同名歌单 | 接收端已有同名歌单时，新建为「歌单名-2」 |
| 附带资源 | 封面和歌词随歌曲一起传输 |
| 不传用户数据 | 不传播放次数、收藏状态、最近播放时间 |
| 空间检查 | 接收前检查磁盘空间，不足时提示 |
| 后台 | 应用切到后台后继续传输 |
| 相机权限 | 扫码需要相机权限；被拒时说明原因并提供「前往设置」 |

### 3.10 本地备份与恢复

档位为 Free，不读写订阅状态。和二维码分享相互独立：分享是局域网内选曲传输，备份是把整个曲库导出成 `.tunehaven` 文件。

**备份内容**：

| 包含 | 不包含 |
|------|--------|
| 歌曲元数据、收藏状态 | 账号、iCloud、订阅状态 |
| 音频文件（默认包含，可改为仅元数据） | WebDAV 账号与密码 |
| 封面和歌词 | 播放次数、跳过记录、搜索历史 |
| 自建歌单、分组及其顺序 | 进行中的定时关闭 |
| 主题、默认播放模式、速度记忆方式、歌词字形 | 最近播放、Apple Music DRM 内容 |

「我喜欢」不单独导出，恢复时按收藏状态重建；「最近播放」不恢复。

**导出**：设置 → 备份与恢复 → 导出备份。导出前显示预估大小，接近 4GB 时建议关闭「包含音频」，超过 4GB 拒绝导出。导出后通过系统分享保存到「文件」等位置。

**恢复入口**：设置 → 备份与恢复 → 从备份恢复；或在「文件」等 App 中直接打开 `.tunehaven`。从外部打开时，如果全屏播放器或其他弹窗正开着，会先收起再进入恢复页，播放不中断；如果收起期间用户又打开了播放器或付费墙，这次不弹恢复页，提示稍后再从「文件」打开。

**恢复模式**：

| 模式 | 行为 |
|------|------|
| 合并（默认） | 保留现有曲库。歌曲冲突默认跳过，歌单冲突默认合并（保留已有歌曲，补上缺少的）。可改为替换或另存副本，可「应用到全部」或逐条设置 |
| 替换曲库 | 二次确认后清空自建歌曲、歌单和分组，再导入备份。系统歌单保留 |
| 仅恢复偏好 | 只恢复主题和播放设置，不改歌曲和歌单 |

**冲突判定**：标题 + 艺术家 + 专辑 + 时长（相差小于 2 秒）相同视为同一首；匹配不到时退回到标题 + 艺术家。空专辑和「未知专辑」视为相同。合并时选择替换、但备份不含该歌音频的，只更新文字信息和收藏，保留本地音频。

**安全**：

- 恢复失败时撤销本次所有改动，已有歌曲不受影响
- 只能在复制文件阶段、写入曲库之前取消
- 恢复不改变订阅状态
- 恢复前不检查磁盘空间
- 临时文件在每次冷启动时清空；从外部打开的副本在恢复结束、取消或关闭恢复页后删除，不会删除「文件」中的原始备份

### 3.11 订阅（Premium）

**商品**：

| 商品 | 类型 | 说明 |
|------|------|------|
| 年度订阅 | 自动续期订阅 | 价格以 App Store 配置为准（规划 ¥12.9/年） |
| 终身买断 | 非消耗型 | 价格以 App Store 配置为准（规划 ¥39.9） |

**试用**：从首次下载起 30 天内享有全部 Premium 功能。删除重装不会重置正式下载的试用起点。

**状态流转**：首次下载 → 试用期 → 到期后为 Free；订阅或买断后为 Premium。优先级：终身买断 > 有效订阅 > 试用期 > Free。

**权限矩阵**：

| 功能 | Free | Premium（订阅 / 买断 / 试用） |
|------|------|-------------------------------|
| 有损播放、曲库、歌单、搜索 | ✅ | ✅ |
| 文件 / Apple Music / 云盘 / WiFi 导入、二维码分享、本地备份 | ✅ | ✅ |
| 云霞、晴屿、月晕三套主题 | ✅ | ✅ |
| 无损播放（含锁屏和控制中心发起的播放） | ❌ | ✅ |
| WebDAV 导入 | ❌ | ✅ |
| 在线歌词（自动匹配和手动搜索） | ❌ | ✅ |

**产品原则**：

1. 启动时只同步订阅状态，不用全屏页挡住用户
2. 上表 Free 功能对所有人完全开放
3. 只在用户触碰 Premium 功能时弹出付费墙，且付费墙必须同时提供价格与续费说明、购买、**恢复购买**、**关闭**、Apple EULA 和隐私政策链接。禁止假关闭、隐藏恢复购买、恐吓倒计时
4. 到期温和降级：正在播放的有损歌曲不打断；正在播放的无损歌曲暂停并弹出付费墙
5. 以 App Store 购买记录为准，联网失败时不能剥夺已购权益

**门控行为**：

| 场景 | 行为 |
|------|------|
| Free 用户播放无损歌曲 | 不播放，弹出可关闭的付费墙；全屏播放页开着时，付费墙显示在播放页之上 |
| 上一首/下一首遇到无损歌曲 | 停在该歌曲并弹出付费墙，不静默跳过 |
| 冷启动恢复的上次歌曲是无损 | Free 用户不恢复这首歌，也不弹付费墙；若随后确认为 Premium（启动时只是本地推断为 Free），补回这首歌，不自动播放，用户已选了别的歌则不覆盖 |
| WebDAV 导入 | 入口显示「Premium 专属功能」，点击弹出付费墙 |
| 在线歌词 | 自动匹配静默跳过，手动搜索提示升级 |
| 购买或恢复购买成功 | 付费墙自动关闭 |

**购买反馈**：付费墙区分正在加载方案、无法获取方案、购买处理中、等待批准与用户取消。等待批准显示说明，不授予权益、不关闭页面，避免重复购买；实际交易更新并确认订阅或终身权益后关闭。购买取消不报错，恢复购买失败保留重试入口。

**订阅管理**（设置列表第一项，默认折叠）：显示试用剩余天数、订阅到期日、终身买断或 Free；提供「查看 Premium 权益」（非 Premium 或试用中时显示）、「恢复购买」、「管理订阅」（打开 Apple 订阅管理页）。

**上架前检查**：隐私政策地址 `https://tunehaven.app/privacy` 不由本仓库托管，提审前必须确认可以公开访问。

## 5. 隐私

- 音乐文件、歌单、设置和播放记录只保存在设备上
- 不内置广告，不接入追踪或统计 SDK
- WiFi 传输和二维码分享只在局域网内进行
- 只有三种情况会联网：购买和恢复购买（Apple）、在线歌词（把歌名和歌手发给歌词服务）、用户自己配置的 WebDAV 服务器
- 删除应用即可清除所有本地数据（Apple 记录的首次下载日期除外）

## 6. 风险

| 风险 | 应对 |
|------|------|
| 部分格式或编码播放不兼容 | 只接受白名单格式，加载失败时提示 |
| 曲库很大时查询变慢 | 数据库索引、列表懒加载 |
| 大量封面占用内存 | 内存缓存 50MB、内存警告时清空；磁盘封面为正式存储，不淘汰 |
| 系统中断后台音频 | 正确配置音频会话和中断处理 |
| WiFi 传输明文 | 页面提示风险，可选密码；后续考虑 HTTPS |
| 本地播放器市场有限 | 突出无广告、隐私、主题和交互细节 |
