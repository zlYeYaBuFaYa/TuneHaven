## 1. 产品概述

| 项目 | 内容 |
|------|------|
| 产品名称 | TuneHaven |
| 产品类型 | iOS 本地优先音乐播放器 |
| 目标平台 | iOS 18.0+（iPhone / iPad） |
| 目标用户 | 18–45 岁、有本地音乐收藏的 iOS 用户 |

曲库、有损播放、歌单和本地导入完全离线可用，无需订阅；无损播放、高级主题、WebDAV 导入、在线歌词属于 Premium（见 3.11）。不内置广告，曲库默认不离开设备。

典型场景：通勤离线听歌、运动时后台播放、工作时循环播放、睡前定时关闭。

产品约束：

- iOS 沙盒不能扫描整个文件系统，导入必须由用户主动发起
- Apple Music 中受 DRM 保护的歌曲无法导出，导入时过滤掉

## 2. 页面结构

- **底部 Tab**：音乐库 / 歌单 / 设置，3 个纯文字 Tab，选中项下方显示小圆点。各 Tab 的导航栈互相独立，切换 Tab 不丢失页面状态
- **迷你播放器**：悬浮在 Tab 栏上方，所有 Tab 共用。显示封面、歌名、收藏、播放/暂停、下一首和进度，点击展开全屏播放页
- **全屏播放页**：封面、歌曲信息、进度条、播放控制、播放模式、歌词预览。可进入歌词全屏页、播放队列，以及「更多」里的定时关闭和倍速。向下拖拽关闭

| Tab | 内容 |
|-----|------|
| 音乐库 | 顶部标签「全部 / 艺术家 / 专辑」+ 搜索栏 + 列表 |
| 歌单 | 系统歌单（我喜欢、最近播放）置顶，下方是自建歌单与分组 |
| 设置 | 见 3.12 |

## 3. 功能规格

### 3.1 音乐导入

| 方式 | 说明 | 档位 |
|------|------|------|
| 文件导入 | 用系统文件选择器选取音频文件 | Free |
| Apple Music 导入 | 扫描设备上已下载的本地媒体库，过滤 DRM 歌曲后导出一份独立副本（之后在「音乐」App 删除不受影响）。MP3、AAC、ALAC、PCM 原样保留音质；已导入过的歌曲直接跳过；点「关闭」后导入在后台继续 | Free |
| 云盘导入 | 通过系统文件选择器从已安装的云盘 App 选取文件，目前列出百度网盘 | Free |
| WiFi 传输 | 同一局域网内用电脑浏览器上传，支持拖拽和扫码打开页面 | Free |
| 从其他 App 打开 | 在其他 App 中用「用 TuneHaven 打开」分享音频文件，自动导入 | Free |
| WebDAV 导入 | 管理多个 WebDAV 账户（如坚果云、NAS），浏览目录并下载导入 | Premium |

**支持格式**：MP3、M4A、AAC、ALAC、WAV、FLAC、AIFF/AIF、CAF。单文件不超过 500MB。

**无损判定**（决定是否需要 Premium）：FLAC、WAV、AIFF、CAF 为无损；M4A/ALAC 编码器为 ALAC，或码率高于 600kbps 时为无损；其余为有损。

**元数据**：导入时读取标题、艺术家、专辑、时长、封面、内嵌歌词、采样率、码率等。缺失时，标题用文件名，艺术家显示「未知艺术家」，专辑显示「未知专辑」，封面用占位图。

**去重**：按文件内容（SHA256）判重，重复文件跳过。

**进度与结果**：导入中显示进度条、当前文件名、已完成数/总数和预计剩余时间。结束后弹窗汇总，页面内分类统计：成功 / 重复跳过 / 格式不支持 / 超过大小 / 失败。

**WiFi 传输规则**：

| 规则 | 说明 |
|------|------|
| 密码保护 | 可选 6 位数字密码，可自动生成或自定义。开启后，浏览器必须先通过密码验证才能上传；停止服务或更换密码后需要重新验证 |
| 防暴力破解 | 同一 IP 连续输错 5 次，冷却 30 秒 |
| 新设备提醒 | 传输过程中有新设备连接时提醒用户确认 |
| 安全提示 | 使用 HTTP 明文传输，页面上提示风险 |

### 3.2 播放

**基础控制**：播放/暂停、上一首/下一首、拖动进度。上一首在已播放超过 3 秒时回到本曲开头。

**播放模式**：

| 模式 | 下一首 | 队列全部播完后 |
|------|--------|----------------|
| 顺序播放 | 按顺序找下一首未播放的歌 | 停止 |
| 单曲循环 | 重复当前歌曲 | — |
| 列表循环 | 按顺序找下一首未播放的歌 | 清除已播放标记，从头开始 |
| 随机播放 | 在未播放的歌中按权重随机挑选 | 清除已播放标记，继续随机 |

**跳过偏好**：每首歌记录一个「不喜欢次数」（上限 5）。随机播放的权重为 `1 / (1 + 不喜欢次数)`；顺序和列表循环会跳过不喜欢次数 ≥ 3 的歌。

**倍速**：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 1.75x / 2.0x，变速不变调。速度记忆可选「全局」（切歌保持当前速度，默认）或「单曲」（每首歌单独记忆）。

**定时关闭**：15 / 30 / 45 / 60 / 90 分钟，可中途取消。到时自动暂停。

**后台与锁屏**：退到后台继续播放。锁屏和控制中心显示歌名、艺术家、封面和进度，支持播放/暂停、上一首/下一首和拖动进度。来电等中断结束后自动恢复，拔出耳机时暂停。

**启动恢复**：冷启动时恢复上次播放的歌曲，但不自动开始播放。

### 3.3 播放队列

- 播放某个列表中的歌曲时，用该列表（全部歌曲、艺术家、专辑、歌单、最近播放等）重建队列
- 查看队列、拖拽排序、移除单首、清空、把当前队列保存为歌单
- 长按歌曲选择「下一首播放」，插入到当前歌曲之后
- 容量上限 999 首
- 已播放的歌留在队列中，只做标记
- 队列不持久化，关闭应用后清空

### 3.4 音乐库

**浏览**：

| 视图 | 展示 | 说明 |
|------|------|------|
| 全部 | 列表 | 可排序，可按格式筛选（MP3、M4A、FLAC 等） |
| 艺术家 | 分组列表 | 点击进入艺术家详情 |
| 专辑 | 封面网格 | 点击进入专辑详情 |

**排序**：名称、艺术家、专辑、导入时间、文件大小、时长。再次点击当前排序项切换升/降序；点击其他项切换过去并默认升序。排序选择会被记住。

**歌曲操作**（各列表按场景提供其中一部分）：

| 手势 | 操作 |
|------|------|
| 右滑 | 喜欢 / 取消喜欢 |
| 左滑 | 删除（从音乐库删除，或在自建歌单里移出歌单） |
| 长按 | 喜欢、下一首播放、添加到歌单、删除 |

**收藏**：收藏状态和系统歌单「我喜欢」双向同步。

**删除与撤销**：从音乐库删除需要先确认。删除后底部提示条保留 30 秒，可撤销；超时后才真正删除文件。同一个文件只有在没有任何歌曲记录引用时才会被物理删除。从歌单移出只解除关联，不删歌曲。

**音频缺失**：从仅含元数据的备份恢复的歌曲显示「未找到」。之后导入同一首歌的文件时自动挂回原记录，保留收藏和播放次数。

### 3.5 搜索

档位为 Free，不需要联网，也不会触发付费墙。

**范围与匹配**：搜索歌名、艺术家、专辑。

- 原文包含：「里香」能搜到「七里香」，拉丁字母不区分大小写
- 拼音全拼：从音节开头做前缀匹配，`zhou`、`zh` 能搜到「周杰伦」，`qili` 能搜到「七里香」
- 拼音首字母：连续匹配，`qlx` 能搜到「七里香」
- 容错：拉丁输入长度 ≥ 3 时，允许和整段全拼或整段首字母相差 1 个字符。单个拉丁字母不走拼音匹配
- 拼音在本机生成（多音字取常用读音），不联网，不上传曲库

**音乐库搜索**：输入停止 300ms 后搜索。在「艺术家」「专辑」标签下只匹配对应字段。结果中的歌曲支持删除、收藏、添加到歌单、下一首播放，操作后结果自动刷新。

**歌单内搜索**：在歌单详情顶部，输入即过滤，匹配规则同上。有搜索词时隐藏歌单头部（封面、名称、简介）。

**无结果**：显示空状态，并提示「试试拼音首字母」。

**搜索历史**：

- 搜索框获得焦点且内容为空时显示
- 「全部 / 艺术家 / 专辑」三个标签分别保存，每个标签最多 10 条，按时间倒序，相同关键词只保留最新一次
- 点击历史词立即搜索；左滑删除单条；可清空当前标签的历史
- 设置 → 存储与隐私 可清除全部搜索历史

### 3.6 歌单

**系统歌单**（不可删除、不可重命名、不能分享）：

- 我喜欢：始终排第一，内容来自歌曲的收藏状态，按收藏时间倒序
- 最近播放：去重展示，时间范围可设为 3 / 7 / 14 / 30 天或全部（默认 7 天），最多加载 1000 首

**自建歌单**：

- 新建/编辑：名称必填，简介选填
- 命名规则：自动去掉首尾空白；不能为空；不能叫「我喜欢」或「最近播放」；不限制特殊字符
- 删除歌单需确认，不影响歌曲本身
- 歌单列表可拖拽排序
- 封面：自动取前 4 首歌的封面拼成 2×2 宫格，不足 4 首时用占位图补齐

**分组**：新建、重命名、删除分组（组内歌单回到未分组），把歌单移入或移出分组，分组可排序。

**批量添加歌曲**：歌曲按艺术家分组展示，支持搜索、全选/取消全选，已在歌单中的歌曲置灰。

### 3.7 歌词

**来源优先级**：

1. 音频文件内嵌歌词
2. 本地歌词文件：用户导入的 .lrc 文件或手动输入的歌词
3. 在线自动匹配（Premium，可在设置里关闭）：依次尝试精确匹配、歌名+艺术家、仅歌名、简化歌名（去掉括号、feat.、remix 等）。全部失败后，这首歌 7 天内不再自动匹配；网络错误不计入

**手动操作**：在线搜索并选择歌词（Premium）、导入 .lrc 文件、粘贴 LRC 或纯文本歌词、删除歌词。纯音乐会标注「器乐曲（无歌词）」。

**显示**：

- 滚动展示，自动跟随进度。当前行加粗，并按行内进度从左到右用主题主色填充（卡拉 OK 效果）；其他行距离越远越淡
- 双指缩放调整字号
- 歌词字形：默认显示简体（繁体自动转换），可在 设置 → 播放 改为「原文」。播放页预览和歌词全屏页使用同一设置
- 在歌词全屏页左滑或下滑返回播放页

### 3.8 主题

| 主题 | 色彩模式 | 风格 | 档位 |
|------|---------|------|------|
| 素云白简（默认） | 浅色 | 清新自然绿 | Free |
| 晴空蔚蓝 | 浅色 | 天空蓝 | Free |
| 暮光玫瑰 | 深色 | 玫瑰粉 | Premium |
| 星际穹顶 | 深色 | 电子青，带星空粒子动画背景 | Premium |

- 每套主题固定深色或浅色，不单独提供深浅色切换
- 切换后立即生效并保存，下次启动恢复
- 旧版本的主题标识自动迁移为素云白简
- 文字颜色对比度满足 4.5:1

### 3.9 二维码分享直传

两台设备在同一 WiFi 下，直接传输歌曲或歌单，不经过外部服务器或 iCloud。档位为 Free。

**入口**：设置 → 分享 →「发送歌曲 / 歌单」或「扫码接收」。

**发送**：选择歌曲或歌单（可多选）→ 生成二维码 → 等待对方扫码 → 显示传输进度。

**接收**：扫码 → 显示传输分析（新增歌曲数、已有可跳过数、各歌单关联本地歌曲数、预估大小）→ 确认后接收 → 显示传输阶段、进度和当前文件 → 完成后汇总（接收数、跳过数、新建歌单数、关联本地歌曲数）。

**规则**：

| 规则 | 说明 |
|------|------|
| 跳过已有歌曲 | 接收端已有的歌曲（标题 + 艺术家相同）不再传输 |
| 歌单关联 | 歌单中接收端已有的歌曲直接关联本地歌曲 |
| 分组 | 携带分组名，接收端没有该分组时自动创建 |
| 同名歌单 | 接收端已有同名歌单时，新建为「歌单名-2」 |
| 附带资源 | 封面和歌词随歌曲一起传输 |
| 不传用户数据 | 不传播放次数、收藏状态、最近播放时间 |
| 空间检查 | 接收前检查磁盘空间，不足时提示 |
| 后台 | 应用切到后台后继续传输 |
| 相机权限 | 扫码需要相机权限；被拒时说明原因并提供「前往设置」 |

### 3.10 本地备份与恢复

档位为 Free，不读写订阅状态。和二维码分享相互独立：分享是局域网内选曲传输，备份是把整个曲库导出成 `.tunehaven` 文件。

**备份内容**：

| 包含 | 不包含 |
|------|--------|
| 歌曲元数据、收藏状态 | 账号、iCloud、订阅状态 |
| 音频文件（默认包含，可改为仅元数据） | WebDAV 账号与密码 |
| 封面和歌词 | 播放次数、跳过记录、搜索历史 |
| 自建歌单、分组及其顺序 | 进行中的定时关闭 |
| 主题、默认播放模式、速度记忆方式、歌词字形 | 最近播放、Apple Music DRM 内容 |

「我喜欢」不单独导出，恢复时按收藏状态重建；「最近播放」不恢复。

**导出**：设置 → 备份与恢复 → 导出备份。导出前显示预估大小，接近 4GB 时建议关闭「包含音频」，超过 4GB 拒绝导出。导出后通过系统分享保存到「文件」等位置。

**恢复入口**：设置 → 备份与恢复 → 从备份恢复；或在「文件」等 App 中直接打开 `.tunehaven`。从外部打开时，如果全屏播放器或其他弹窗正开着，会先收起再进入恢复页，播放不中断；如果收起期间用户又打开了播放器或付费墙，这次不弹恢复页，提示稍后再从「文件」打开。

**恢复模式**：

| 模式 | 行为 |
|------|------|
| 合并（默认） | 保留现有曲库。歌曲冲突默认跳过，歌单冲突默认合并（保留已有歌曲，补上缺少的）。可改为替换或另存副本，可「应用到全部」或逐条设置 |
| 替换曲库 | 二次确认后清空自建歌曲、歌单和分组，再导入备份。系统歌单保留 |
| 仅恢复偏好 | 只恢复主题和播放设置，不改歌曲和歌单 |

**冲突判定**：标题 + 艺术家 + 专辑 + 时长（相差小于 2 秒）相同视为同一首；匹配不到时退回到标题 + 艺术家。空专辑和「未知专辑」视为相同。合并时选择替换、但备份不含该歌音频的，只更新文字信息和收藏，保留本地音频。

**安全**：

- 恢复失败时撤销本次所有改动，已有歌曲不受影响
- 只能在复制文件阶段、写入曲库之前取消
- 恢复不改变订阅状态；Free 用户不能借备份恢复 Premium 主题
- 恢复前不检查磁盘空间
- 临时文件在每次冷启动时清空；从外部打开的副本在恢复结束、取消或关闭恢复页后删除，不会删除「文件」中的原始备份

### 3.11 订阅（Premium）

**商品**：

| 商品 | 类型 | 说明 |
|------|------|------|
| 年度订阅 | 自动续期订阅 | 价格以 App Store 配置为准（规划 ¥12.9/年） |
| 终身买断 | 非消耗型 | 价格以 App Store 配置为准（规划 ¥39.9） |

**试用**：从首次下载起 30 天内享有全部 Premium 功能。删除重装不会重置正式下载的试用起点。

**状态流转**：首次下载 → 试用期 → 到期后为 Free；订阅或买断后为 Premium。优先级：终身买断 > 有效订阅 > 试用期 > Free。

**权限矩阵**：

| 功能 | Free | Premium（订阅 / 买断 / 试用） |
|------|------|-------------------------------|
| 有损播放、曲库、歌单、搜索 | ✅ | ✅ |
| 文件 / Apple Music / 云盘 / WiFi 导入、二维码分享、本地备份 | ✅ | ✅ |
| 素云白简、晴空蔚蓝 | ✅ | ✅ |
| 无损播放（含锁屏和控制中心发起的播放） | ❌ | ✅ |
| 暮光玫瑰、星际穹顶 | ❌ | ✅ |
| WebDAV 导入 | ❌ | ✅ |
| 在线歌词（自动匹配和手动搜索） | ❌ | ✅ |

**产品原则**：

1. 启动时只同步订阅状态，不用全屏页挡住用户
2. 上表 Free 功能对所有人完全开放
3. 只在用户触碰 Premium 功能时弹出付费墙，且付费墙必须同时提供价格与续费说明、购买、**恢复购买**、**关闭**、Apple EULA 和隐私政策链接。禁止假关闭、隐藏恢复购买、恐吓倒计时
4. 到期温和降级：正在播放的有损歌曲不打断；正在播放的无损歌曲暂停并弹出付费墙；高级主题回退到素云白简
5. 以 App Store 购买记录为准，联网失败时不能剥夺已购权益

**门控行为**：

| 场景 | 行为 |
|------|------|
| Free 用户播放无损歌曲 | 不播放，弹出可关闭的付费墙；全屏播放页开着时，付费墙显示在播放页之上 |
| 上一首/下一首遇到无损歌曲 | 停在该歌曲并弹出付费墙，不静默跳过 |
| 冷启动恢复的上次歌曲是无损 | Free 用户不恢复这首歌，也不弹付费墙 |
| 选择高级主题 | 主题上显示锁，点击弹出付费墙 |
| WebDAV 导入 | 入口显示「Premium 专属功能」，点击弹出付费墙 |
| 在线歌词 | 自动匹配静默跳过，手动搜索提示升级 |
| 购买或恢复购买成功 | 付费墙自动关闭 |

**订阅管理**（设置列表第一项，默认折叠）：显示试用剩余天数、订阅到期日、终身买断或 Free；提供「查看 Premium 权益」（非 Premium 或试用中时显示）、「恢复购买」、「管理订阅」（打开 Apple 订阅管理页）。

**上架前检查**：隐私政策地址 `https://tunehaven.app/privacy` 不由本仓库托管，提审前必须确认可以公开访问。

## 5. 隐私

- 音乐文件、歌单、设置和播放记录只保存在设备上
- 不内置广告，不接入追踪或统计 SDK
- WiFi 传输和二维码分享只在局域网内进行
- 只有三种情况会联网：购买和恢复购买（Apple）、在线歌词（把歌名和歌手发给歌词服务）、用户自己配置的 WebDAV 服务器
- 删除应用即可清除所有本地数据（Apple 记录的首次下载日期除外）

## 6. 风险

| 风险 | 应对 |
|------|------|
| 部分格式或编码播放不兼容 | 只接受白名单格式，加载失败时提示 |
| 曲库很大时查询变慢 | 数据库索引、列表懒加载 |
| 大量封面占用内存 | 内存加磁盘两级缓存，缓存上限可调 |
| 系统中断后台音频 | 正确配置音频会话和中断处理 |
| WiFi 传输明文 | 页面提示风险，可选密码；后续考虑 HTTPS |
| 本地播放器市场有限 | 突出无广告、隐私、主题和交互细节 |
