# 7g／7f UI 实施检查

日期：2026-11-17。设备：iPhone 17 模拟器，iOS 27.2。

## 7g 付费墙

- 移除装饰渐变，使用三主题语义色、浅色图标底和胶囊主操作。
- 商品异步到达后选择有效方案；加载中与暂无商品分开显示；支持重试。
- 购买接口返回成功／待审批／取消。等待批准有明确说明，不当成成功、不授予权益、不重复购买；交易更新到订阅／终身权益后关闭页面。
- 恢复购买期间禁用重复操作，失败保留可见提示。
- `SubscriptionPurchaseFeedbackTests` 的 3 个测试覆盖等待审批、批准后清理状态、取消原样返回。

## 7f 分享页面

- 七个页面统一语义色与控件；发送／接收、选择、预览、传输结果保留既有流程。
- 二维码使用固定白底确保扫描；摄像取景的文字、遮罩保留高对比度，权限说明支持 Dynamic Type，设置按钮最小 48 pt。
- 选歌无结果有说明，未选择内容不能开始分享；接收部分失败不再显示全部完成。
- 没有修改 ShareService、网络协议、令牌、接收去重与文件处理逻辑。

- 全量单元回归：627 项 Swift Testing + 2 项 XCTest 通过；另有 4 项 UI 测试通过（导入 3、分享选择 1）。
- 最后仅做分享结果颜色／文案、付费墙标题与格式微调，最终版本另行编译通过。
- 截图：`paywall-light.png`、`paywall-dark.png`、`share.send-light.png`、`share.send-dark.png`。
