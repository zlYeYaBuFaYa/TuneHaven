# TuneHaven · 柔光 UI 设计提案

正式设计规格：[UI 设计文档](../../UI设计文档.md) · [交互设计文档](../../交互设计文档.md)。

基于 TuneHaven 的 SwiftUI 页面结构与用户提供的三张色彩参考，提供三套视觉方案，每套两个页面。交付为设计效果图及独立 HTML 预览；封面、曲名、艺术家、歌词与数量均为设计演示内容。没有接入真实音乐数据。

## 交付

- `a-board.png`：云霞，音乐库与播放器。粉色、雾蓝、淡紫；三套中最接近参考图的柔光气质。
- `b-board.png`：晴屿，歌单与播放器。薄荷与暖杏；文件夹形状表达收藏，圆形唱片表达播放。
- `c-board.png`：月晕，专辑库与歌词播放器。冰蓝与淡紫；封面陈列、深色当前歌词、安静留白。
- `screens/`：六张独立页面，780 × 1688 PNG。
- `index.html`：三套方案的完整画廊。可搜索演示歌曲、切换播放图标和收藏状态。其他按钮仅提示演示用途，不代表已经实现业务。
- `assets/`：原创 SVG 概念封面，无外部图片或字体请求。
- `render.cjs`：导出脚本；需要 Node.js、Playwright 和本机 Chrome。
- `verification.json`：图片加载、文字裁切、横向溢出与基础交互检查结果。

整体效果图为 3200 × 2280 PNG；每屏按 390 × 844 逻辑尺寸设计，二倍导出。

## 设计依据与取舍

保留音乐库、歌单、设置三个一级入口。导入操作放在音乐库右上角，创建操作放在歌单右上角；迷你播放器附着在主导航上方。全屏播放器沿用收起、收藏、进度、播放模式、上一首、播放/暂停、下一首、队列与音频输出。

从截图提取低饱和多色光晕、浅色材质、细白边和深色主操作。去掉短视频界面的社交操作和字幕，避免带入不属于音乐播放器的信息。没有把整套界面做成相同的大卡片：云霞使用歌曲列表，晴屿使用收藏夹，月晕使用专辑陈列。

色彩留在背景与内容层；悬浮导航与迷你播放器用模糊材质模拟。内容卡片使用浅色填充和细边，不模拟 Liquid Glass 折射。HTML 材质是效果稿近似；SwiftUI 落地时优先使用系统 TabView 与附件、标准 Material，以及相应系统的玻璃按钮样式。

晴屿：绿 `#BDE5D8`、杏 `#FFE1BD`、浅绿 `#DBEDDC`、底 `#F6FAF7`、操作 `#243C34`、次文字 `#4D6059`。

CSS 预留减少透明度、增强对比度和减少动画的适配。原生落地时，字号采用 SwiftUI 语义文本样式，允许辅助功能字号使横向内容换行，并使用系统材质响应辅助功能设置。此次交付已补充三套对应的黑夜模式；动态字号与真实设备体验留待选定方案后的原生实现验证。

## 验证与复现

已用本机 Chrome 渲染并逐版目视检查。六屏图片加载正常，无检测到的标题裁切或横向溢出；收藏、播放状态和歌曲搜索演示通过。进一步调整后仍需重新目视检查。

```sh
NODE_PATH=/path/to/node_modules node render.cjs
```

使用技能：`ui-ux-pro-max`、`apple-design`。参考本地 HIG 的 Accessibility、Layout、Typography、Color、Designing for iOS、Tab bars、Materials、Liquid Glass、Playing audio；本稿为视觉探索，不宣称已完成原生无障碍认证。


## 黑夜模式补充

新增 `dark-a-board.png`、`dark-b-board.png`、`dark-c-board.png`，每款仍为两个对应页面、3200 × 2280 PNG。`screens/dark-*.png` 为六张独立页面。

`dark.html` 为黑夜画廊入口，可与日间画廊互相切换；由 `render.cjs` 基于 `index.html` 生成，共用原有页面结构与业务演示。`dark.css` 提供三套夜间配色。更新基础稿后运行以下命令同步生成入口与导出：

```sh
NODE_PATH=/path/to/node_modules node render.cjs --dark
```

- 云霞 / Afterglow：玫瑰 `#512D48`、烟蓝 `#263A54`、紫 `#3C3055`、底色 `#16141E`、浅粉主操作 `#E4C5DB`。主文字 `#EEE9F1`，次文字 `#B6ADBF`。
- 晴屿 / Night Garden：墨绿 `#1B493C`、琥珀 `#51422C`、深绿 `#233D33`、底色 `#121C18`、浅绿主操作 `#C0DDC9`。主文字 `#EAF0E9`，次文字 `#B0C3B7`。
- 月晕 / Midnight Interlude：午夜蓝 `#203E68`、紫 `#3E315F`、蓝灰 `#293C61`、底色 `#141B2C`、浅蓝主操作 `#C6D0EE`。主文字 `#E8EDF7`，次文字 `#B1BDD5`。

封面保持同一份素材，在 CSS 中略降亮度与饱和度。按钮采用各主题的浅色，暗色导航略高于背景亮度；描边降低到半透明细线。没有对日间图直接反相。

黑夜图逐张目视检查通过，浏览器运行无异常、六屏无横向溢出和检测到的标题裁切，图片加载与收藏、播放、搜索演示正常。对五个不透明背景色标逐一计算 WCAG 对比度：云霞主文字最低 9.66:1、次文字 5.34:1；晴屿为 8.38:1 / 5.23:1；月晕为 9.17:1 / 5.70:1。数字仅对应配色令牌测试，实际渐变及透明混色另做了目视检查，并非每个渲染像素的自动无障碍审计。完整结果在 `dark-verification.json`。
