## 发现问题（9 个，全部已修复）

### 🔴 阻塞（1 个）

1. **ShareSongSelectorView / SharePlaylistSelectorView 调用 `dismiss()` 导致 sheet 关闭**
   - 问题：选择器嵌在 ShareSendView 的 Group switch 中，不是独立 sheet。`dismiss()` 关闭整个 sheet，用户选完歌曲后看不到二维码。同时嵌套 NavigationStack 与父级冲突。
   - 修复：移除 `dismiss()` 调用、移除 `@Environment(\.dismiss)`、移除嵌套 `NavigationStack`。选择完成后仅回调 `onSelected`，由父视图 ShareSendView 切换 phase。

### 🟡 重要（4 个）

2. **ShareService.connectAndAnalyze 异常时状态未清理**
   - 问题：`client.connect` 或 `fetchSongList` 抛异常时，`isReceiving` 保持 true，`client` 不清理。
   - 修复：包裹 do/catch，catch 中调用 `client.disconnect()`、置空 `client`、重置 `isReceiving`/`receiveProgress`。

3. **QRScannerView 相机权限拒绝时无提示**
   - 问题：`.denied`/`.restricted` 状态下用户只看到黑屏。
   - 修复：新增 `showPermissionDeniedUI()` 方法，显示提示文案 + "前往设置" 按钮。

4. **ShareServer Content-Disposition 不支持中文文件名**
   - 问题：`filename="\(fileName)"` 对非 ASCII 字符不安全。
   - 修复：新增 `contentDisposition(for:)` 方法，ASCII 文件名用 `filename=`，非 ASCII 用 `filename*=utf-8''` 编码。

5. **ShareReceiveView 传输失败时未调用 cancelReceive**
   - 问题：`executeReceive` catch 中只重设 phase，连接不清理。
   - 修复：catch 中先调用 `shareService.cancelReceive()`，再设错误消息。

### 🟢 轻微（4 个）

6. **ShareServer.handleInfo 中 `var info2 = info` 赋值冗余** → 改为 `let enriched = ShareSessionInfo(...)`
7. **ShareService.playlistSongs 中 `.enumerated()` 多余** → 改为 `.compactMap { song in ... }`
8. **ShareSendView 和 ShareReceiveView 中 `phaseLabel` 重复** → 提取为 `SharePhase.label` 计算属性
9. **ShareServer.matchPath 每次创建 NSRegularExpression** → 缓存为 `static let routePatterns`
