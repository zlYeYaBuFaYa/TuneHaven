## 第 1 轮发现并修复的问题

### 1. [🟡] handleNewConnection 竞态条件

**问题**：旧连接 `cancel()` 后，其 `stateUpdateHandler(.cancelled)` 异步回调会将 `activeConnection` 置 nil，但此时 `activeConnection` 已指向新连接，导致新连接被误清。

**修复**：
- 取消旧连接前先 `active.stateUpdateHandler = nil`
- 新连接 handler 增加 `self.activeConnection === connection` 身份校验

**涉及文件**：`ShareServer.swift:99-112`

### 2. [🟢] importCover 下载封面后未更新 coverImagePath

**问题**：`importCover` 下载封面到 `{songId}_medium.jpg` 但未更新 Song 的 `coverImagePath`。如果音频文件无嵌入封面，Song 实体不引用该封面文件，封面无法显示。

**修复**：
- `SongRepository` 协议已有 `updateCoverPath` 方法
- `CoreDataSongRepository` 新增实现
- `importCover` 在 `importedSong.coverImagePath == nil` 时调用 `songRepo.updateCoverPath`

**涉及文件**：`CoreDataSongRepository.swift:246-257`、`ShareService.swift:471-473`
