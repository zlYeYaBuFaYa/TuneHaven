# 代码 Review：备份预览取消标志（Review T6）- 第 1 轮

> 日期：2026-11-17 | 级别：轻量 | 范围：BackupRestoreService.inspect、BackupTempCleanupTests

## 背景

关闭任意备份页（含导出页）会 `cancel()` 置取消标志，标志只在 `beginWork()`（导出/恢复）里复位。`inspect` 不走 `beginWork`，解包前检查到标志为 true 即抛 `backupCancelled`：本次启动内关过一次备份页后，恢复预览一直报「已取消」。

## 改动

`inspect` 开始时，若 `!isBusy && extractInFlight == 0`，复位取消标志。

## 已知限制（不修）

关闭页面时上一次预览的解包仍在进行（`extractInFlight > 0`），立刻打开另一个备份并预览，这一次仍会报「已取消」；解包结束后再预览即正常。需要包很大且操作很快才会出现，属解包不可取消（Review T6 低危项）的延伸。
