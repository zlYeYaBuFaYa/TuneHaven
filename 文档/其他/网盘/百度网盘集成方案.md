# 百度网盘 Open API 集成方案

> 版本：v1.1（修正版）  
> 日期：2026-03-19  
> 状态：待开发

---

## 一、需求概述

将 TuneHaven 现有的"系统文件选择器"云盘导入方案，替换为 **App 内直接集成百度网盘 Open API**，实现：

1. 用户在 App 内完成百度账号 OAuth 授权登录
2. 在 App 内浏览百度网盘目录结构，仅展示文件夹和音频文件
3. 支持多选音频文件，通过 dlink 下载到本地
4. 下载完成后走现有 ImportService 导入流程
5. Token 自动续期，用户无需反复登录

---

## 二、百度网盘 API 概况

### 2.1 核心 API

| 功能 | 接口 | 说明 |
|------|------|------|
| 获取文件列表 | `GET /rest/2.0/xpan/file?method=list` | 获取指定目录下的文件列表 |
| 获取文件信息 | `GET /rest/2.0/xpan/multimedia?method=filemetas&dlink=1` | 获取含下载地址的文件详情 |
| 下载文件 | `GET dlink&access_token=xxx` | 通过 dlink 下载，Header 需设 `User-Agent: pan.baidu.com` |
| 获取用户信息 | `GET /rest/2.0/xpan/nas?method=uinfo` | 获取用户名、头像、会员类型 |
| 获取容量信息 | `GET /rest/2.0/xpan/nas?method=uinfo` | 获取网盘使用量/总容量 |

### 2.2 关键约束

| 项目 | 说明 |
|------|------|
| Access Token 有效期 | 30 天（百度硬性规定，不可更改） |
| Refresh Token | 一次性使用，刷新后返回新的 refresh_token |
| dlink 有效期 | 8 小时 |
| dlink 下载要求 | Header 必须设 `User-Agent: pan.baidu.com` |
| 断点续传 | 支持（通过 Range Header） |
| 文件类型标识 | category=2 表示音频文件 |
| 下载限速 | 非 SVIP 用户可能被限速（几十 KB/s ~ 几百 KB/s） |

### 2.3 授权模式选择

| 授权模式 | Token 有效期 | 续期能力 | 适用场景 |
|---------|-------------|---------|---------|
| 简化模式（Implicit Grant） | 30 天 | ❌ 不支持刷新 | 无后端的简单应用 |
| **授权码模式（Authorization Code）** ✅ | 30 天 | ✅ 支持 refresh_token 自动续期 | **本项目采用** |
| 设备码模式（Device Code） | 30 天 | ✅ 支持 | 弱输入设备 |

**选择授权码模式的理由：** 支持 refresh_token，可以在 token 过期前自动刷新，实现用户"登录一次、永不过期"的体验。每次刷新返回新的 access_token + refresh_token，形成滚动续期链。

## 三、前置条件

### 3.1 百度开放平台注册

1. 进入 [百度网盘开放平台](https://pan.baidu.com/union/home)，点击"申请接入"
2. 登录百度帐号
3. 完成开发者认证（个人认证或企业认证）
4. 前往 [控制台](https://pan.baidu.com/union/console/applist) 创建应用
5. 获取 **AppKey**、**SecretKey**、**SignKey**
6. 回调地址配置为：`tunehaven://baidunetdisk/callback`

### 3.2 App 内配置

AppKey 和 SecretKey 支持在**设置页**动态配置，存储于 Keychain（加密），无需硬编码到源码中。开发阶段使用占位符。

## 五、核心流程设计

### 5.1 OAuth 授权流程

```
用户点击"百度网盘"
  │
  ├── Keychain 中有有效 access_token？
  │     ├── 是 → 检查是否即将过期（< 3 天）
  │     │         ├── 是 → 后台自动 refresh → 进入文件浏览器
  │     │         └── 否 → 直接进入文件浏览器
  │     │
  │     └── 否 → Keychain 中有 refresh_token？
  │               ├── 是 → 尝试 refresh
  │               │         ├── 成功 → 进入文件浏览器
  │               │         └── 失败 → 清除旧 token → 发起新授权
  │               └── 否 → 发起新授权
  │
  └── 发起新授权：
        1. ASWebAuthenticationSession 打开百度 OAuth 页面
           URL: https://openapi.baidu.com/oauth/2.0/authorize
             ?response_type=code
             &client_id={AppKey}
             &redirect_uri=tunehaven://baidunetdisk/callback
             &scope=basic,netdisk
        2. 用户登录百度账号并同意授权
        3. 百度重定向: tunehaven://baidunetdisk/callback?code=xxx
        4. App 拦截回调，提取 authorization_code
        5. 用 code 换取 token:
           POST https://openapi.baidu.com/oauth/2.0/token
             grant_type=authorization_code
             &code=xxx
             &client_id={AppKey}
             &client_secret={SecretKey}
             &redirect_uri=tunehaven://baidunetdisk/callback
        6. 存储 access_token + refresh_token + expires_in 到 Keychain
        7. 获取用户信息（用户名、头像）→ 存储到 UserDefaults
        8. 进入文件浏览器
```

### 5.2 Token 自动续期流程

```
每次 API 请求前 → BaiduOAuthManager.validAccessToken()
  │
  ├── token 有效且未过期 → 直接返回 token
  │
  ├── token 即将过期（< 3 天） → 后台刷新
  │     POST https://openapi.baidu.com/oauth/2.0/token
  │       grant_type=refresh_token
  │       &refresh_token={stored_refresh_token}
  │       &client_id={AppKey}
  │       &client_secret={SecretKey}
  │     → 存储新的 access_token + refresh_token + expires_in
  │     → 返回新 token
  │
  └── token 已过期 + refresh 失败 → 抛出 cloudDriveTokenExpired
        → UI 提示用户重新授权
```

### 5.3 文件浏览流程

```
BaiduNetdiskBrowserView（NavigationStack 内嵌）
  │
  ├── 加载目录内容
  │     GET /rest/2.0/xpan/file?method=list
  │       &dir={当前目录路径}
  │       &order=name
  │       &limit=1000
  │       &access_token=xxx
  │     → 过滤：仅保留 isdir=1（文件夹）和 category=2（音频）
  │     → 按类型排序：文件夹在前，文件在后
  │
  ├── UI 展示
  │     ┌────────────────────────────────┐
  │     │ ← 百度网盘    /Music           │ ← 导航栏（显示当前路径）
  │     ├────────────────────────────────┤
  │     │ 📁 我的音乐                     │ ← 文件夹（点击进入子目录）
  │     │ 📁 下载                         │
  │     │ ☐ 🎵 歌曲A.mp3     4.2 MB     │ ← 音频文件（可勾选）
  │     │ ☐ 🎵 歌曲B.flac    28.1 MB    │
  │     │ ☑ 🎵 歌曲C.m4a     5.7 MB     │ ← 已选中
  │     ├────────────────────────────────┤
  │     │ 已选 1 首              [导入]   │ ← 底部操作栏
  │     └────────────────────────────────┘
  │
  ├── 点击文件夹 → NavigationLink push 进入子目录
  ├── 勾选/取消勾选音频文件 → 更新已选列表
  ├── 点击"导入" → 跳转到 BaiduNetdiskDownloadView
  └── 空目录 → 显示 EmptyStateView（"此目录下没有音频文件"）
```

### 5.4 下载与导入流程

```
BaiduNetdiskDownloadView
  │
  ├── 逐文件处理（串行，避免并发触发百度限制）：
  │     1. 获取 dlink:
  │        GET /rest/2.0/xpan/multimedia?method=filemetas
  │          &fsids=[{fsId}]
  │          &dlink=1
  │          &access_token=xxx
  │        → 提取 dlink 字段
  │
  │     2. 下载文件:
  │        URLSession.shared.download(from: dlink&access_token=xxx)
  │          Header: User-Agent: pan.baidu.com
  │        → 下载到 tmp/import_temp/{原始文件名}
  │        → 实时更新下载进度（bytesReceived / totalBytes）
  │
  │     3. 下载完成 → 加入待导入列表
  │     4. 下载失败/超时（10 分钟） → 记录失败，继续下一个
  │
  ├── 全部下载完成 → 调用 ImportService.importFromFiles(urls:)
  │     → 复用现有导入逻辑（去重、元数据解析、复制到 Music 目录）
  │
  └── 展示导入结果
        ┌────────────────────────────────┐
        │           导入结果              │
        ├────────────────────────────────┤
        │ ✅ 成功导入           3 首     │
        │ ⏭️ 已跳过（重复）     1 首     │
        │ ❌ 下载失败           0 首     │
        ├────────────────────────────────┤
        │            [完成]              │
        └────────────────────────────────┘
```


### 6.2 BaiduOAuthToken（令牌模型）

```swift
struct BaiduOAuthToken: Codable {
    let accessToken: String
    let refreshToken: String
    let expiresIn: Int            // 秒数（通常 2592000 = 30天）
    let obtainedAt: Date          // 获取时间

    var expiresAt: Date { obtainedAt.addingTimeInterval(TimeInterval(expiresIn)) }
    var isExpired: Bool { Date() >= expiresAt }
    var isExpiringSoon: Bool { Date() >= expiresAt.addingTimeInterval(-3 * 24 * 3600) }  // < 3天
}
```

## 八、错误处理

### 8.1 新增错误码

| 错误码 | 枚举值 | 触发场景 |
|--------|--------|---------|
| CLD001 | `cloudDriveAuthFailed` | OAuth 授权流程失败（用户取消、网络错误等） |
| CLD002 | `cloudDriveTokenExpired` | Token 过期且 refresh 失败，需重新授权 |
| CLD003 | `cloudDriveRequestFailed(String)` | 百度 API 请求失败（含错误描述） |
| CLD004 | `cloudDriveDownloadFailed(String)` | 文件下载失败（超时、网络中断等） |
| CLD005 | `cloudDriveNotConfigured` | 未配置 AppKey/SecretKey |

### 8.2 错误处理策略

| 场景 | 处理方式 |
|------|---------|
| 未配置 AppKey | 弹窗引导去设置页配置 |
| 授权失败/取消 | Toast 提示，返回云盘列表页 |
| Token 过期 | 自动尝试 refresh → 失败则提示重新授权 |
| API 请求失败 | Toast 提示错误信息，支持重试 |
| 下载超时（10 分钟） | 跳过当前文件，记录失败，继续下一个 |
| 下载被限速 | 界面提示"下载速度取决于百度网盘账号等级" |

## 十三、风险与注意事项

### 13.1 已知风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 非 SVIP 下载限速 | 大文件下载极慢 | UI 提示限速风险 + 超时处理 |
| SecretKey 客户端存储 | 可被逆向提取 | Keychain 加密存储；后续可升级为代理服务 |
| 百度 API 变更 | 接口可能调整 | 封装在 APIClient 层，变更影响范围可控 |
| App Store 审核 | OAuth 相关审核 | 使用 ASWebAuthenticationSession（Apple 推荐方式） |

### 13.2 OAuth 安全要点

- 使用 `ASWebAuthenticationSession` 而非 WKWebView（Apple 审核要求）
- Token 存储于 Keychain（iOS 硬件加密）
- Refresh Token 一次性使用，用后即废
- 授权失败时清除所有旧 Token

### 13.3 性能考量

- 文件列表单次最多请求 1000 条，超出需分页
- 下载采用串行模式（避免触发百度并发限制）
- 下载到 `tmp/import_temp/`，导入后自动清理临时文件
- 单文件下载超时 10 分钟，超时自动跳过
