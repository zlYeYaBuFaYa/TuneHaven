# 方案：订阅系统

> 创建日期：2026-03-29 | 状态：草稿

## 1. 需求概述

为 TuneHaven 接入 App Store 订阅系统，实现以下能力：

**商品体系**：

| 商品 | 类型 | 价格 | 说明 |
|------|------|------|------|
| 年度订阅 | Auto-renewable Subscription | ¥12.9/年 | 自动续费 |
| 终身买断 | Non-consumable | ¥39.9 | 一次性永久解锁 |

**用户状态流转**：

```
首次下载 → 试用期（30天，全功能）→ 试用到期
    → 已订阅/已买断 → Premium
    → 未操作 → Free（功能受限）
```

**权限矩阵**：

| 功能 | Free | Premium（订阅/买断/试用期） |
|------|------|---------------------------|
| 有损音频播放（MP3、AAC） | ✅ | ✅ |
| 无损音频播放（FLAC、WAV、AIFF、ALAC、CAF） | ❌ | ✅ |
| 主题：素云白简、晴空蔚蓝 | ✅ | ✅ |
| 主题：暮光玫瑰、星际穹顶 | ❌ | ✅ |
| 导入：文件 / Apple Music / Cloud Drive / WiFi | ✅ | ✅ |
| 导入：WebDAV | ❌ | ✅ |
| 歌词：内嵌 / 外置 LRC / 手动输入 | ✅ | ✅ |
| 歌词：在线搜索（LRCLIB API） | ❌ | ✅ |
| 其他所有现有功能 | ✅ | ✅ |

**配套功能**：
- 设置页展示订阅状态 + 恢复购买入口
- 付费墙页面（展示商品、价格、权益对比）
- Free 用户触发受限功能时弹出付费墙引导
- 试用到期后自动回退主题到素云白简

## 3. 技术方案

### 3.1 整体设计

```
┌─ Presentation ─────────────────────────────────────────────┐
│  PaywallView / SettingsSubscriptionSection / 各拦截点 UI    │
│      ↓ @EnvironmentObject                                  │
├─ Domain ───────────────────────────────────────────────────┤
│  SubscriptionService (@MainActor ObservableObject)         │
│    - @Published tier: SubscriptionTier                     │
│    - @Published status: SubscriptionStatus                 │
│    - func canAccess(_ feature: PremiumFeature) -> Bool     │
│    - func purchase(_ product) async throws                 │
│    - func restorePurchases() async                         │
│      ↓ SubscriptionProviding (Protocol)                    │
├─ App (StoreKit 2 实现) ───────────────────────────────────┤
│  StoreKitSubscriptionProvider                              │
│    - Product 加载 / Transaction 验证 / AppTransaction 试用 │
└────────────────────────────────────────────────────────────┘
```

**依赖方向**：Presentation → Domain（SubscriptionService）← App（StoreKitSubscriptionProvider 实现 SubscriptionProviding 协议）

**核心设计决策**：
- SubscriptionService 作为 `@MainActor ObservableObject` 注入 SwiftUI 环境，与现有 Service 即 ViewModel 模式一致
- 订阅状态通过 `@Published` 驱动 UI 刷新，所有需要权限校验的 View 只需读取 `subscriptionService.tier`
- StoreKit 2 实现放在 App 层（依赖 StoreKit framework），Domain 层通过 `SubscriptionProviding` 协议解耦
- 试用期通过 `AppTransaction` 获取首次下载日期，纯 Apple 机制不可篡改

import Foundation

/// 用户权限等级
enum SubscriptionTier: String, Codable {
    case free
    case premium
}

/// 用户订阅状态（用于 UI 展示）
enum SubscriptionStatus: Equatable {
    case trial(daysRemaining: Int)      // 试用期，剩余天数
    case subscribed(expiresDate: Date)  // 年度订阅中
    case lifetime                       // 终身买断
    case expired                        // 试用/订阅已过期，Free 用户
    case none                           // 从未有过购买（仅安装但试用过期）
}

/// 受控功能枚举 — 后期新增功能只需添加 case + 配置 requiredTier
enum PremiumFeature: String, CaseIterable {
    case losslessPlayback       // 无损音频播放
    case premiumTheme           // 高级主题（暮光玫瑰、星际穹顶）
    case webDAVImport           // WebDAV 导入
    case onlineLyricsSearch     // 在线歌词搜索

    /// 该功能所需的最低权限等级
    var requiredTier: SubscriptionTier {
        switch self {
        case .losslessPlayback, .premiumTheme, .webDAVImport, .onlineLyricsSearch:
            return .premium
        }
    }

    /// 功能描述（用于付费墙引导文案）
    var displayName: String {
        switch self {
        case .losslessPlayback:   return "无损音质播放"
        case .premiumTheme:       return "高级主题风格"
        case .webDAVImport:       return "WebDAV 导入"
        case .onlineLyricsSearch: return "在线歌词搜索"
        }
    }
}

/// StoreKit 商品标识
enum SubscriptionProductID {
    static let yearlySubscription = "com.tunehaven.subscription.yearly"
    static let lifetimePurchase = "com.tunehaven.lifetime"
    static let allProductIDs: Set<String> = [yearlySubscription, lifetimePurchase]

#### 3.2.2 Domain 层 — 协议定义

**新增文件：`Domain/Repositories/SubscriptionProviding.swift`**

```swift
import Foundation

/// 订阅数据访问协议 — 隔离 Domain 层对 StoreKit 的直接依赖
protocol SubscriptionProviding: Sendable {
    /// 获取可购买商品列表
    func fetchProducts() async throws -> [SubscriptionProduct]
    /// 执行购买
    func purchase(_ productID: String) async throws -> PurchaseResult
    /// 恢复购买
    func restorePurchases() async throws
    /// 检查当前是否有有效的年度订阅
    func hasActiveSubscription() async -> Bool
    /// 检查是否已购买终身买断
    func hasLifetimePurchase() async -> Bool
    /// 获取订阅到期日期（年度订阅）
    func subscriptionExpirationDate() async -> Date?
    /// 获取 App 首次下载日期（用于试用期计算）
    func appOriginalPurchaseDate() async -> Date?
    /// 监听交易更新（返回 AsyncStream 供持续监听）
    func transactionUpdates() -> AsyncStream<TransactionUpdate>
}

/// 商品信息（跨层传递用）
struct SubscriptionProduct: Identifiable {
    let id: String
    let displayName: String
    let displayPrice: String
    let description: String
    let type: ProductType

    enum ProductType {
        case autoRenewable
        case nonConsumable
    }
}

/// 购买结果
enum PurchaseResult {
    case success
    case pending       // 等待审批（家庭共享/Ask to Buy）
    case cancelled     // 用户取消
}

/// 交易更新事件
enum TransactionUpdate {
    case purchased     // 新购买
    case renewed       // 续费成功
    case expired       // 订阅过期
    case revoked       // 被撤销
    case restored      // 恢复购买
}
```

#### 3.2.3 Domain 层 — SubscriptionService

**新增文件：`Domain/Services/SubscriptionService.swift`**

```swift
import Foundation
import Combine

@MainActor
final class SubscriptionService: ObservableObject {
    private let log = AppLogger.shared
    private let provider: SubscriptionProviding

    /// 当前权限等级（驱动全局 UI 刷新）
    @Published private(set) var tier: SubscriptionTier = .free
    /// 当前订阅状态（用于设置页展示）
    @Published private(set) var status: SubscriptionStatus = .none
    /// 可购买商品列表
    @Published private(set) var products: [SubscriptionProduct] = []
    /// 是否正在购买中
    @Published private(set) var isPurchasing = false

    static let trialDurationDays = 30

    init(provider: SubscriptionProviding) {
        self.provider = provider
    }

    // MARK: - 启动时初始化

    func initialize() async {
        await refreshStatus()
        await loadProducts()
        startListeningForUpdates()
    }

    // MARK: - 权限校验（核心方法）

    func canAccess(_ feature: PremiumFeature) -> Bool {
        tier >= feature.requiredTier
    }

    // MARK: - 刷新状态

    func refreshStatus() async {
        // 1. 终身买断最优先
        if await provider.hasLifetimePurchase() {
            tier = .premium
            status = .lifetime
            log.info("[Subscription] 状态: 终身买断")
            return
        }

        // 2. 有效年度订阅
        if await provider.hasActiveSubscription() {
            let expDate = await provider.subscriptionExpirationDate()
            tier = .premium
            status = .subscribed(expiresDate: expDate ?? Date.distantFuture)
            log.info("[Subscription] 状态: 年度订阅有效")
            return
        }

        // 3. 试用期
        if let installDate = await provider.appOriginalPurchaseDate() {
            let daysSinceInstall = Calendar.current.dateComponents(
                [.day], from: installDate, to: Date()
            ).day ?? Int.max

            if daysSinceInstall < Self.trialDurationDays {
                let remaining = Self.trialDurationDays - daysSinceInstall
                tier = .premium
                status = .trial(daysRemaining: remaining)
                log.info("[Subscription] 状态: 试用期 剩余\(remaining)天")
                return
            }
        }

        // 4. 无有效订阅
        tier = .free
        status = .expired
        log.info("[Subscription] 状态: Free 用户")
    }

    // MARK: - 商品加载

    func loadProducts() async {
        do {
            products = try await provider.fetchProducts()
            log.debug("[Subscription] 加载商品: \(products.count) 个")
        } catch {
            log.error("[Subscription] 商品加载失败: \(error.localizedDescription)")
        }
    }

    // MARK: - 购买

    func purchase(_ product: SubscriptionProduct) async throws {
        isPurchasing = true
        defer { isPurchasing = false }

        let result = try await provider.purchase(product.id)
        switch result {
        case .success:
            await refreshStatus()
            log.info("[Subscription] 购买成功: \(product.id)")
        case .pending:
            log.info("[Subscription] 购买等待审批: \(product.id)")
        case .cancelled:
            log.info("[Subscription] 用户取消购买: \(product.id)")
        }
    }

    // MARK: - 恢复购买

    func restorePurchases() async {
        do {
            try await provider.restorePurchases()
            await refreshStatus()
            log.info("[Subscription] 恢复购买完成")
        } catch {
            log.error("[Subscription] 恢复购买失败: \(error.localizedDescription)")
        }
    }

    // MARK: - 监听交易更新

    private func startListeningForUpdates() {
        Task {
            for await update in provider.transactionUpdates() {
                log.debug("[Subscription] 收到交易更新: \(update)")
                await refreshStatus()
            }
        }
    }
}

// MARK: - SubscriptionTier Comparable

extension SubscriptionTier: Comparable {
    static func < (lhs: SubscriptionTier, rhs: SubscriptionTier) -> Bool {
        let order: [SubscriptionTier] = [.free, .premium]
        let lhsIndex = order.firstIndex(of: lhs) ?? 0
        let rhsIndex = order.firstIndex(of: rhs) ?? 0
        return lhsIndex < rhsIndex
    }
}
```

#### 3.2.4 App 层 — StoreKit 2 实现

**新增文件：`App/StoreKitSubscriptionProvider.swift`**

```swift
import StoreKit
import Foundation

final class StoreKitSubscriptionProvider: SubscriptionProviding {
    private let log = AppLogger.shared

    // MARK: - 商品加载

    func fetchProducts() async throws -> [SubscriptionProduct] {
        let storeProducts = try await Product.products(
            for: SubscriptionProductID.allProductIDs
        )
        return storeProducts.map { product in
            SubscriptionProduct(
                id: product.id,
                displayName: product.displayName,
                displayPrice: product.displayPrice,
                description: product.description,
                type: product.type == .autoRenewable ? .autoRenewable : .nonConsumable
            )
        }
    }

    // MARK: - 购买

    func purchase(_ productID: String) async throws -> PurchaseResult {
        let products = try await Product.products(for: [productID])
        guard let product = products.first else {
            throw AppError.purchaseFailed("商品不存在")
        }

        let result = try await product.purchase()
        switch result {
        case .success(let verification):
            let transaction = try checkVerified(verification)
            await transaction.finish()
            return .success
        case .pending:
            return .pending
        case .userCancelled:
            return .cancelled
        @unknown default:
            return .cancelled
        }
    }

    // MARK: - 恢复购买

    func restorePurchases() async throws {
        try await AppStore.sync()
    }

    // MARK: - 订阅状态查询

    func hasActiveSubscription() async -> Bool {
        for await result in Transaction.currentEntitlements {
            if let transaction = try? checkVerified(result),
               transaction.productID == SubscriptionProductID.yearlySubscription,
               transaction.revocationDate == nil {
                return true
            }
        }
        return false
    }

    func hasLifetimePurchase() async -> Bool {
        for await result in Transaction.currentEntitlements {
            if let transaction = try? checkVerified(result),
               transaction.productID == SubscriptionProductID.lifetimePurchase,
               transaction.revocationDate == nil {
                return true
            }
        }
        return false
    }

    func subscriptionExpirationDate() async -> Date? {
        for await result in Transaction.currentEntitlements {
            if let transaction = try? checkVerified(result),
               transaction.productID == SubscriptionProductID.yearlySubscription {
                return transaction.expirationDate
            }
        }
        return nil
    }

    // MARK: - App 首次下载日期（试用期）

    func appOriginalPurchaseDate() async -> Date? {
        do {
            let appTransaction = try await AppTransaction.shared
            switch appTransaction {
            case .verified(let transaction):
                return transaction.originalPurchaseDate
            case .unverified:
                // 验证失败时回退到本地缓存
                return UserDefaults.standard.object(
                    forKey: AppStorageKey.appFirstLaunchDate
                ) as? Date
            }
        } catch {
            log.error("[StoreKit] AppTransaction 获取失败: \(error)")
            return UserDefaults.standard.object(
                forKey: AppStorageKey.appFirstLaunchDate
            ) as? Date
        }
    }

    // MARK: - 交易更新监听

    func transactionUpdates() -> AsyncStream<TransactionUpdate> {
        AsyncStream { continuation in
            let task = Task {
                for await result in Transaction.updates {
                    guard let transaction = try? self.checkVerified(result) else { continue }
                    await transaction.finish()

                    if transaction.revocationDate != nil {
                        continuation.yield(.revoked)
                    } else if transaction.expirationDate != nil,
                              let expDate = transaction.expirationDate,
                              expDate < Date() {
                        continuation.yield(.expired)
                    } else {
                        continuation.yield(.purchased)
                    }
                }
                continuation.finish()
            }
            continuation.onTermination = { _ in task.cancel() }
        }
    }

    // MARK: - 验证

    private func checkVerified<T>(_ result: VerificationResult<T>) throws -> T {
        switch result {
        case .verified(let safe):
            return safe
        case .unverified(_, let error):
            throw error
        }
    }
}
```

#### 3.2.5 Song 无损判定扩展

**修改文件：`Domain/Entities/Song.swift`**

新增 `isLossless` 计算属性：

```swift
extension Song {
    /// 判断歌曲是否为无损格式
    var isLossless: Bool {
        let fmt = metadata.format.lowercased()
        switch fmt {
        case "flac", "wav", "aiff", "aif", "caf":
            return true
        case "m4a", "alac":
            // M4A 容器需检查编码器: ALAC = 无损, AAC = 有损
            if let encoder = metadata.encoder?.lowercased() {
                return encoder.contains("alac") || encoder.contains("apple lossless")
            }
            // 无编码器信息时按比特率判断: > 1000kbps 视为无损
            if let bitRate = metadata.bitRate, bitRate > 1000 {
                return true
            }
            return fmt == "alac"
        default:
            return false
        }
    }
}
```

func searchOnline(title: String, artist: String?) async throws -> [LRCLibTrack] {

### 3.3 备选方案

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| A. SubscriptionService 持有 Provider 协议（当前方案） | 解耦、可测试、符合 Clean Architecture | 多一层抽象 | ✅ 采用 |
| B. SubscriptionService 直接调用 StoreKit 2 | 代码更少 | Domain 层直接依赖 StoreKit，破坏分层 | ❌ 不采用 |
| C. 权限校验放在各 View 中分散处理 | 无需统一服务 | 分散、难维护、后期扩展困难 | ❌ 不采用 |

## 6. 风险评估

| 风险 | 等级 | 应对策略 |
|------|------|---------|
| AppTransaction 在 Sandbox 环境行为不一致 | 🟡 中 | 开发阶段使用 StoreKit Configuration File 模拟；`appFirstLaunchDate` 作为兜底 |
| App Store 审核可能要求调整付费墙文案 | 🟡 中 | 遵循 Apple 订阅 UI 规范：明确展示价格、续费周期、取消方式 |
| 用户在试用期内设置了 Premium 主题，到期后 UI 闪烁 | 🟢 低 | 到期后在 `refreshStatus()` 中触发主题回退，下次打开生效 |
| PlaybackService 新增依赖可能影响已有测试 | 🟢 低 | 通过 Mock SubscriptionProviding 注入测试，已有测试不受影响 |
| 队列中全为无损歌曲，Free 用户递归 playNext 可能栈溢出 | 🟡 中 | 增加最大跳过计数（如 50），超限停止播放并提示 |
| 首次启动无网络时 AppTransaction 可能获取失败 | 🟢 低 | 兜底方案：记录 `appFirstLaunchDate` 到 UserDefaults |
