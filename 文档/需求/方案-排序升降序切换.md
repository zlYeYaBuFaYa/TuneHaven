# 方案：排序升降序切换

> 创建日期：2026-03-20 | 状态：已完成

## 1. 需求概述

音乐库"全部"歌曲列表排序菜单支持升降序切换：

- 点击已选中的排序项时，切换升降序方向
- 点击未选中的排序项时，选中该项并默认升序
- 排序菜单中用箭头图标指示当前选中项的排序方向
- 排序偏好（排序项 + 方向）持久化到 UserDefaults，下次启动恢复

## 2. 现状分析

### 相关代码

| 文件 | 现状 |
|------|------|
| AllSongsView.swift | 排序菜单 `ascending` 硬编码为 `true`，无升降序切换 |
| LibraryMainView.swift | `sortOption` 作为 @State 传递给 AllSongsView，未持久化 |
| MusicLibraryService.swift | `loadSongs(sortBy:ascending:)` 已支持 ascending 参数 |
| CoreDataSongRepository.swift | `fetchAll(sortBy:ascending:)` 已支持 ascending 参数 |
| SongSortOption (LibraryTypes.swift) | 6 种排序选项，有 displayName |

### 需修改的文件清单

| 文件 | 改动 |
|------|------|
| AllSongsView.swift | 排序菜单交互逻辑 + ascending 状态 |
| LibraryMainView.swift | 增加 isAscending 状态 + 持久化 |

## 3. 技术方案

### 3.1 整体设计

**状态管理：**

```
LibraryMainView:
  @AppStorage("sort_option") sortOptionRaw: Int = 0     → SongSortOption
  @AppStorage("sort_ascending") isAscending: Bool = true → 升降序方向

  传递给 AllSongsView:
    @Binding var sortOption: SongSortOption
    @Binding var isAscending: Bool
```

使用 `@AppStorage` 替代 `@State`，自动持久化到 UserDefaults。

**交互逻辑：**

```
用户点击排序项 X：
  if X == 当前选中项:
    isAscending.toggle()     → 切换方向
  else:
    sortOption = X           → 切换排序项
    isAscending = true       → 重置为升序

  → 调用 loadSongs(sortBy: sortOption, ascending: isAscending)
```

### 3.2 详细实现

#### 3.2.1 LibraryMainView 改动

将 `@State private var sortOption` 替换为 `@AppStorage`：

```swift
@AppStorage("song_sort_option") private var sortOptionRaw: Int = SongSortOption.title.rawValue
@AppStorage("song_sort_ascending") private var isAscending: Bool = true

private var sortOption: SongSortOption {
    get { SongSortOption(rawValue: sortOptionRaw) ?? .title }
    set { sortOptionRaw = newValue.rawValue }
}
```

AllSongsView 初始化增加 isAscending 绑定：

```swift
AllSongsView(sortOption: $sortOptionBinding, isAscending: $isAscending, formatFilter: $formatFilter)
```

由于 @AppStorage 的 Int 无法直接生成 Binding<SongSortOption>，需要手动构建 Binding：

```swift
private var sortOptionBinding: Binding<SongSortOption> {
    Binding(
        get: { SongSortOption(rawValue: sortOptionRaw) ?? .title },
        set: { sortOptionRaw = $0.rawValue }
    )
}
```

#### 3.2.2 AllSongsView 改动

增加 isAscending 绑定参数：

```swift
@Binding var isAscending: Bool
```

修改排序菜单交互：

```swift
Menu {
    ForEach(SongSortOption.allCases, id: \.self) { opt in
        Button {
            if sortOption == opt {
                isAscending.toggle()
            } else {
                sortOption = opt
                isAscending = true
            }
            Task { await libraryService.loadSongs(sortBy: sortOption, ascending: isAscending) }
        } label: {
            HStack {
                Text(opt.displayName)
                if sortOption == opt {
                    Image(systemName: isAscending ? "chevron.up" : "chevron.down")
                }
            }
        }
    }
} label: {
    HStack(spacing: 4) {
        Image(systemName: isAscending ? "arrow.up" : "arrow.down")
        Text(sortOption.displayName)
    }
    .font(.caption)
    .foregroundColor(palette.textSecondary)
}
```

#### 3.2.3 启动时恢复排序偏好

在 LibraryMainView.onAppear 或 AllSongsView.onAppear 中，使用持久化的排序偏好加载歌曲。当前 `loadSongs()` 在 TuneHavenApp 启动时调用，默认 sortBy:.title, ascending:true。

在 AllSongsView.onAppear 中补充一次按持久化偏好加载：

```swift
.onAppear {
    recomputeDisplaySongs()
    Task { await libraryService.loadSongs(sortBy: sortOption, ascending: isAscending) }
}
```

## 4. 影响范围

| 范围 | 影响 |
|------|------|
| LibraryMainView | sortOption 和 isAscending 改为 @AppStorage |
| AllSongsView | 新增 isAscending 绑定，排序菜单交互逻辑修改 |
| 其他页面 | 无影响 |
| 向后兼容 | 完全兼容，首次使用默认升序 |

## 5. 测试要点

| 场景 | 预期 |
|------|------|
| 点击未选中排序项 | 切换到该排序项，升序 |
| 点击已选中排序项 | 方向切换（升→降 或 降→升） |
| 排序菜单图标 | 选中项显示 ↑ 或 ↓ 方向图标 |
| 杀死 App 后重启 | 排序项和方向恢复上次选择 |
| 格式过滤 + 排序方向 | 两者独立生效，互不干扰 |

## 6. 风险评估

| 风险 | 等级 | 应对 |
|------|------|------|
| @AppStorage 与 @State Binding 的兼容性 | 低 | 手动构建 Binding 解决 |
| 启动时多次 loadSongs | 低 | onAppear 调用覆盖启动默认值，CoreData 查询轻量 |
