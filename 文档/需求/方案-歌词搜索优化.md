# 方案：歌词搜索优化

> 创建日期：2026-03-20 | 状态：已完成

## 1. 需求概述

优化在线歌词搜索体验，解决繁体歌词和冷门歌曲匹配率低的问题：

**4a. 繁简切换：**
- 歌词页面增加繁体/简体切换按钮
- 使用 CFStringTransform 进行繁简转换
- 记住用户偏好（UserDefaults）

**4b. 降级搜索策略：**
- 自动搜索歌词时，按以下顺序降级尝试：
  ① 精确匹配（歌名+艺术家+专辑+时长）
  ② 歌名+艺术家（search API）
  ③ 仅歌名
  ④ 简化歌名（去除括号内容、feat.、remix 等后缀）
- 任一级别命中即停止

**4c. 手动编辑歌词：**
- 歌词搜索页增加"手动输入歌词"入口
- 支持粘贴 LRC 格式文本
- 解析并保存到本地 Documents/Lyrics/ 目录

## 3. 技术方案

### 3.1 繁简切换（4a）

**实现方式：** 在 LyricsPageView 的 header 区域增加繁简切换按钮。

**转换逻辑：**

```swift
extension String {
    var toSimplifiedChinese: String {
        let mutable = NSMutableString(string: self)
        CFStringTransform(mutable, nil, "Traditional-Simplified" as CFString, false)
        return mutable as String
    }

    var toTraditionalChinese: String {
        let mutable = NSMutableString(string: self)
        CFStringTransform(mutable, nil, "Simplified-Traditional" as CFString, false)
        return mutable as String
    }
}
```

**状态管理：**

```swift
// LyricsPageView 中
@AppStorage("lyrics_simplified") private var preferSimplified: Bool = false
```

**歌词转换应用：**

不修改原始 LyricsData，而是在展示层对歌词行文本做实时转换：

```swift
private func displayText(for line: LyricsLine) -> String {
    preferSimplified ? line.text.toSimplifiedChinese : line.text
}
```

**按钮 UI：** 在歌词页面 header 区域增加一个小按钮（"简/繁"文字切换），点击切换状态。

### 3.2 降级搜索策略（4b）

**修改 `LyricsService.autoMatchOnline(for:)`：**

当前只调用 `api.get()` 精确匹配一次。改为降级链：

```swift
func autoMatchOnline(for song: Song) async -> LyricsData? {
    guard !isCooldownActive(for: song.id) else { return nil }

    // Level 1: 精确匹配（现有逻辑）
    if let data = try? await exactMatch(song: song) { return data }

    do {
        // Level 2: search API — 歌名 + 艺术家
        if let data = try await searchMatch(title: song.title, artist: song.artist, songId: song.id) { return data }

        // Level 3: search API — 仅歌名
        if song.artist != "未知艺术家" {
            if let data = try await searchMatch(title: song.title, artist: nil, songId: song.id) { return data }
        }

        // Level 4: search API — 简化歌名
        let simplified = simplifyTitle(song.title)
        if simplified != song.title {
            if let data = try await searchMatch(title: simplified, artist: nil, songId: song.id) { return data }
        }
    } catch {
        // 网络错误时不 cooldown，下次可重试
        log.debug("降级搜索网络错误: \(error.localizedDescription)")
        return nil
    }

    // 所有级别均未命中，标记 cooldown
    markCooldown(for: song.id)
    return nil
}
```

**辅助方法：**

```swift
private func exactMatch(song: Song) async throws -> LyricsData? {
    let track = try await api.get(
        trackName: song.title,
        artistName: song.artist,
        albumName: song.album,
        duration: Int(song.duration)
    )
    return try await processTrack(track, songId: song.id, songTitle: song.title)
}

private func searchMatch(title: String, artist: String?, songId: UUID) async throws -> LyricsData? {
    let results = try await api.search(trackName: title, artistName: artist)
    let candidates = results.filter { !$0.instrumental && $0.hasAnyLyrics }
    // 优先选择有时间轴歌词的结果
    let best = candidates.first(where: { $0.hasSyncedLyrics }) ?? candidates.first
    guard let best else { return nil }
    return try await processTrack(best, songId: songId, songTitle: title)
}

private func processTrack(_ track: LRCLibTrack?, songId: UUID, songTitle: String) async throws -> LyricsData? {
    guard let track, !track.instrumental, let lyrics = track.bestLyrics else { return nil }
    cleanupOldLRC(songTitle: songTitle)
    try await saveLyricsFile(lyrics, for: songId)
    let lines = parseLRC(lyrics)
    if lines.isEmpty {
        return LyricsData(source: .file, lines: buildPlainLines(from: lyrics), rawText: lyrics)
    }
    return LyricsData(source: .file, lines: lines, rawText: lyrics)
}

private func simplifyTitle(_ title: String) -> String {
    var result = title
    // 去除括号内容：(xxx)、（xxx）、[xxx]
    let patterns = [#"\(.*?\)"#, #"（.*?）"#, #"\[.*?\]"#]
    for pattern in patterns {
        result = result.replacingOccurrences(of: pattern, with: "", options: .regularExpression)
    }
    // 去除常见后缀
    let suffixes = ["feat.", "ft.", "remix", "live", "acoustic", "version", "remastered"]
    let lower = result.lowercased()
    for suffix in suffixes {
        if let range = lower.range(of: suffix) {
            result = String(result[result.startIndex..<range.lowerBound])
        }
    }
    return result.trimmingCharacters(in: .whitespaces)
}
```

### 3.3 手动编辑歌词（4c）

**在 LyricsSearchView 中增加"手动输入歌词"入口：**

在搜索表单下方增加一个按钮，点击后展开文本编辑区域：

```swift
@State private var showManualInput = false
@State private var manualLyricsText = ""
```

**UI 布局：**

在搜索结果区域底部（或当搜索无结果时显著展示）增加"手动输入歌词"按钮。点击后导航到一个 TextEditor 页面，用户可以粘贴 LRC 格式文本。

```swift
Button {
    showManualInput = true
} label: {
    Label("手动输入歌词", systemImage: "square.and.pencil")
}

// sheet 中展示 ManualLyricsInputView
```

**ManualLyricsInputView（内联在 LyricsSearchView 中）：**

```swift
private var manualInputView: some View {
    NavigationStack {
        VStack {
            Text("粘贴 LRC 格式歌词或纯文本歌词")
                .font(.caption)
                .foregroundColor(palette.textSecondary)
            TextEditor(text: $manualLyricsText)
                .font(.system(.body, design: .monospaced))
            // 保存按钮
        }
        .navigationTitle("手动输入歌词")
        .toolbar {
            ToolbarItem(placement: .confirmationAction) {
                Button("保存") { saveManualLyrics() }
            }
        }
    }
}
```

**保存逻辑：** 调用 `LyricsService.shared.saveLyrics(manualLyricsText, for: song)`，复用已有保存方法。

## 5. 测试要点

| 场景 | 预期 |
|------|------|
| 繁简切换按钮 | 点击后歌词文本在繁体/简体间切换 |
| 繁简偏好持久化 | 杀死 App 后重启，繁简偏好保持 |
| 降级搜索 — Level 1 命中 | 精确匹配成功，不触发后续级别 |
| 降级搜索 — Level 2 命中 | 精确匹配失败，search API（歌名+艺术家）成功 |
| 降级搜索 — Level 3 命中 | 前两级失败，仅歌名搜索成功 |
| 降级搜索 — Level 4 命中 | 简化歌名搜索成功 |
| 降级搜索 — 全部失败 | 标记 cooldown，7 天内不重试 |
| 手动输入 LRC 格式 | 解析成功，歌词同步显示 |
| 手动输入纯文本 | 保存成功，歌词按行显示 |
| 手动输入空内容 | 保存按钮禁用 |

## 6. 风险评估

| 风险 | 等级 | 应对 |
|------|------|------|
| 降级搜索增加 API 请求次数 | 中 | 仅在上一级失败时才触发下一级；cooldown 机制防止频繁重试 |
| CFStringTransform 繁简转换精度 | 低 | 系统 API，转换质量高；不修改原始数据，仅展示层转换 |
| 手动输入的 LRC 格式校验 | 低 | parseLRC 已有容错，无效行自动跳过；纯文本也能正常展示 |
| search API 返回大量结果 | 低 | searchMatch 取第一个匹配结果；用户手动搜索时展示完整列表 |
