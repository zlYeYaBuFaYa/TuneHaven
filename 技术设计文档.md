# 技术设计文档

> 本文档聚焦系统技术设计：架构、核心服务 API、关键流程、导航/主题系统、并发模型、性能策略与错误处理。项目目录结构与数据库 Schema 请参阅项目文档，产品需求请参阅需求文档。

## 一、整体架构

### 1.1 分层架构

Clean Architecture + MVVM，自顶向下四层：

```
App Layer        -- 应用入口、导航路由、主题系统
Presentation     -- SwiftUI View + @ObservableObject Service（充当 ViewModel）
Domain           -- Entity、Service、Repository Protocol
Data             -- CoreData Repository 实现、Entity Mapper、MetadataParser
Core             -- AudioEngine、Cache、Network、Persistence、Storage
```

依赖方向严格单向：上层可依赖下层，下层不得反向依赖。Domain 层通过 Repository Protocol 定义数据访问接口，Data 层提供实现。

### 1.2 服务层设计

所有核心 Service 采用 `@MainActor final class: ObservableObject` 模式，Service 自身就是 ViewModel，View 直接通过 `@StateObject` 或 `@EnvironmentObject` 持有。`@Published` 属性驱动 UI 刷新，`@MainActor` 保证线程安全。

### 1.3 单例组件

| 组件 | 原因 |
|------|------|
| AudioEngine | 全局唯一 AVPlayer |
| PlaybackService | 播放状态全局共享 |
| CoreDataStack | 持久化容器唯一 |
| ImageCacheManager | 缓存统一管理 |
| ErrorLogger | 全局日志收集 |
| NowPlayingManager | 系统 Now Playing 信息 |
| AudioSessionManager | 音频会话管理 |
| FileStorageService | 文件操作入口 |

## 三、核心服务 API

### 3.1 PlaybackService -- 播放控制

全局单例，管理播放状态、队列、速度和睡眠定时。

**状态属性：** currentSong: Song?, isPlaying: Bool, currentTime/duration: TimeInterval, playMode: PlayMode, playbackSpeed: Float, sleepTimerRemaining: TimeInterval?

**播放模式：**

| 模式 | 行为 |
|------|------|
| sequential | 顺序播放，到末尾停止 |
| repeatOne | 单曲循环 |
| repeatAll | 列表循环（全部播完后重置标记重头开始） |
| shuffle | 加权随机（权重 = 1/(1+dislikeCount)，不喜欢越多概率越低） |

**核心方法：**

```swift
func play(song: Song, in context: PlayContext) async   // 播放并按上下文构建队列
func prepare(song: Song, in context: PlayContext) async // 预加载不自动播放
func togglePlayPause()
func playNext()
func playPrevious()                                     // 超过 3 秒时回到歌曲开头
func seek(to time: TimeInterval)
func skip(by seconds: TimeInterval)
func stop()
func cyclePlayMode()
func setSpeed(_ speed: Float)                           // 支持全局/单曲两种记忆
func setSleepTimer(minutes: Int?)
func dislikeAndSkip() async                             // 标记不喜欢并跳过
```

**PlayContext 播放上下文：**

```swift
enum PlayContext {
    case allSongs(sortBy: SortField)
    case album(name: String, artist: String)
    case artist(name: String)
    case playlist(id: UUID)
    case queue                                          // 直接从队列播放，不重建
}
```

**速度记忆模式（UserDefaults speed_memory_mode）：**
- 0（默认）：全局统一速度，存于 `playback_speed`
- 1：单曲独立速度，存于 `per_song_speeds` 字典

**播放恢复：** 启动时从 UserDefaults `last_played_song_id` 恢复上次歌曲（不自动播放）。

## 四、音频引擎

### 4.1 AudioEngine

基于 AVPlayer 封装，全局单例。

**状态机：** idle -> loading -> playing/paused/error(Error)

**支持格式：** mp3, m4a, aac, alac, wav, flac, aiff, aif, caf

```swift
@MainActor
final class AudioEngine: ObservableObject {
    @Published var state: PlaybackState = .idle
    @Published var currentTime: TimeInterval = 0
    @Published var duration: TimeInterval = 0

    func load(url: URL) async       // 验证文件 -> 校验格式 -> 加载 AVURLAsset -> 创建 PlayerItem
    func play() / pause() / togglePlayPause()
    func seek(to: TimeInterval) / skip(by: TimeInterval)
    func stop()
    func setSpeed(_ speed: Float)

    var onPlaybackEnded: (() -> Void)?
    var onTimeUpdate: ((TimeInterval, TimeInterval) -> Void)?
}
```

**音频加载流程：** 验证文件存在 -> 校验扩展名 -> 激活音频会话 -> AVURLAsset.load(.isPlayable) -> 创建 AVPlayerItem + KVO 观察 -> 替换 player item -> 添加时间观察器（0.5s 间隔）

**AudioEngineError（引擎内部错误）：** fileNotFound(URL), unsupportedFormat(String), assetNotPlayable(URL), loadFailed(underlying: Error)

### 4.2 音频中断处理

| 事件 | 处理 |
|------|------|
| 音频中断开始 | 自动暂停 |
| 音频中断结束 + shouldResume | 恢复播放并还原变速 |
| 音频路由变更（拔出耳机） | 自动暂停 |

### 4.3 NowPlayingManager

管理锁屏/控制中心信息和远程控制命令：

```swift
func update(song:currentTime:duration:speed:cover:)     // 全量更新
func updateElapsedTime(currentTime:duration:speed:)      // 轻量更新（仅进度）
func setupRemoteCommands(onPlay:onPause:onNext:onPrevious:onSeek:)
```

远程命令：play/pause -> AudioEngine, nextTrack/previousTrack -> PlaybackService, changePlaybackPosition -> AudioEngine.seek

## 六、并发模型

### 6.1 @MainActor 策略

所有 ObservableObject Service 标注 `@MainActor`，保证 `@Published` 属性读写始终在主线程：

PlaybackService, MusicLibraryService, PlaylistService, PlayQueueService, ImportService, WiFiTransferServer, AudioEngine 均为 `@MainActor`。

### 6.2 Core Data 双上下文

```swift
final class CoreDataStack {
    // 读取路径（Main Queue）-- UI 绑定
    var viewContext: NSManagedObjectContext { container.viewContext }

    // 写入路径（Private Queue）-- 避免阻塞主线程
    lazy var backgroundContext: NSManagedObjectContext = {
        let ctx = container.newBackgroundContext()
        ctx.mergePolicy = NSMergeByPropertyObjectTrumpMergePolicy
        return ctx
    }()

    func performBackground<T>(_ block: @escaping (NSManagedObjectContext) throws -> T) async throws -> T
}
```

- viewContext 开启 `automaticallyMergesChangesFromParent`，backgroundContext 保存后变更自动合并到主线程
- 两个上下文均使用 `NSMergeByPropertyObjectTrumpMergePolicy`（内存值优先）
- `performBackground` 通过 `withCheckedThrowingContinuation` 桥接为 async/await

### 6.3 Combine + async/await 协作

Combine 用于响应式状态绑定，async/await 用于异步操作。sink 回调中通过 `Task { @MainActor in }` 桥接回主线程：

```swift
engine.$state.sink { [weak self] state in
    Task { @MainActor [weak self] in
        guard let self else { return }
        if case .playing = state { self.isPlaying = true }
    }
}.store(in: &cancellables)
```

## 七、关键业务流程

### 7.1 播放流程

```
用户点击歌曲 -> PlaybackService.play(song:in:)
  +-- 同一首歌正在播放 -> 返回
  +-- 同一首歌已暂停 -> engine.play()
  +-- 新歌曲:
      -> buildQueue(): 按 PlayContext 查询歌曲列表 -> replaceQueue()
      -> loadAndPlay():
         1. 保存 last_played_song_id
         2. 验证文件存在
         3. AudioSessionManager.ensureActive()
         4. AudioEngine.load(url:)
         5. applySpeedForSong() -- 速度记忆
         6. engine.play()
         7. libraryService.recordPlay()
         8. NowPlayingManager.update()
```

### 7.2 文件导入流程

```
用户选择文件 -> ImportService.importFromFiles(urls:)
逐个文件 processFile():
  1. 校验扩展名（supportedExtensions）
  2. startAccessingSecurityScopedResource()
  3. 校验大小（<= 500MB）
  4. SHA256 哈希 -> 查重
  5. AudioMetadataParser 解析元数据
  6. copyToMusic() 复制到 Documents/Music/
  7. ThumbnailGenerator 生成封面缩略图 -> Caches/CoverImages/
  8. 构建 Song -> CoreDataSongRepository.insert()
  -> 返回 ImportResult
```

### 7.3 软删除流程

```
用户删除 -> softDeleted = true
         -> 文件移至 tmp/pending_delete/
         -> Snackbar 显示 30 秒
           +-- 撤销: softDeleted = false, 文件移回
           +-- 超时: 物理删除文件和数据库记录
```

### 7.4 歌单管理流程

```
PlaylistService -> CoreDataPlaylistRepository (backgroundContext 写入)
               -> save() -> viewContext 自动合并
               -> loadPlaylists() -> @Published 更新 -> UI 刷新
```

## 九、性能策略

### 9.1 图片缓存

ImageCacheManager 两级缓存：NSCache（内存）-> Caches/CoverImages/（磁盘）-> 从 ID3 标签提取。

- **内存缓存：** NSCache, totalCostLimit 50MB, 内存警告时清空
- **磁盘缓存：** 默认上限 100MB，最大 300MB，LRU 淘汰（超限时删除最旧 20%）
- **UserDefaults** `image_cache_limit_mb` 控制上限

### 9.2 音频时间更新

时间观察器间隔 0.5 秒，平衡进度条平滑度和 CPU 开销。NowPlayingManager 提供 `updateElapsedTime` 轻量方法，仅修改进度字段而不重建整个 info 字典。

### 9.3 文件去重

导入时 SHA256 全文件哈希去重，哈希存入 Song.fileHash 字段。

### 9.4 AVPlayer 优化

```swift
player.automaticallyWaitsToMinimizeStalling = false   // 减少启动延迟
player.allowsExternalPlayback = false                  // 禁用 AirPlay 视频
```
